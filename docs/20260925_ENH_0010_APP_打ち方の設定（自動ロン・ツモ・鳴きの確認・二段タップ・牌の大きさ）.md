# 打ち方の設定（自動ロン・ツモ、鳴きの確認、自動ツモ切り、二段タップ、牌の大きさ）

- 管理番号: #0010
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0004（横画面の卓）、#0005（設定画面）

## 概要

麻雀アプリとして標準的な「打ち方」の設定を足した。設定画面の「打ち方」にまとめ、対局中でも右上のメニュー → 設定から変えられる。

## 対象ファイル

- `index.html`
- `README.md`

## 変更内容

| 設定 | 初期値 | 中身 |
|---|---|---|
| 自動でロン・ツモ | OFF | あがれる時にボタンを押さずにあがる。ツモは「設定により自動であがります」と案内してから、ロンは聞かずにあがる |
| 鳴きの確認 | 出す | 「出さない」にすると、ポン・チー・カン（大明槓）の確認を出さず、ロンだけ聞く。鳴きたくない時に確認で止まらない |
| リーチ後の自動ツモ切り | ON | リーチ中に引いた牌があがり牌でなければ、0.7秒後に自動で切る。カン（暗槓）の選択がある時は待つ |
| 二段タップ | 触って操作する端末はON、それ以外はOFF | 1回目のタップで牌を選んで持ち上げ、同じ牌をもう一度タップで捨てる。別の牌をタップすると選び直し。リーチ中（切れる牌が1枚）と自動ツモ切りでは1回で切る。レッスンでは使わない |
| 牌を大きめに | OFF | 手牌の大きさの上限を約2割広げる。狭い画面ではボタンが手牌の上に浮く配置になる |

- いずれも端末に保存（`mjAutoWin`・`mjNoCall`・`mjAutoTg`・`mjTwoTap`・`mjTileBig`）
- オンラインの参加者の端末では、あがりと鳴きの判断は部屋主に送る作りのため、自動ロン・ツモと鳴きの確認の設定は効かない（参加者の手番の操作だけ）
- レッスン（道場・物語の教え）ではこれらの自動化を使わない。教える手順どおりに押してもらうため

## 確認URL

| 環境 | URL |
|---|---|
| ローカル | http://127.0.0.1:8766/index.html |
| 本番 | https://kiyotake1229.github.io/mahjong/ |

確認した内容：

- 二段タップ：1回目で `.sel`（持ち上がり）になり手牌は減らず、2回目で捨てられること
- 自動でロン・ツモ：あがり牌を引いた時にボタンを押さずに和了画面になること
- 鳴きの確認「出さない」：ポンできる場面で確認が出ず次の手番へ進むこと。「出す」に戻すと「ポン／スルー」が出ること
- リーチ後の自動ツモ切り：リーチ中にあがり牌でない牌を引くと自動で切られ、手番が進むこと
- 牌を大きめに：844×390 で手牌が大きくなり、ボタンが手牌の上に浮く配置に切り替わること
- 設定画面（844×390）で「打ち方」の5項目が表示・切り替えできること
