## 変更内容

### 1. Capacitor プロジェクト

| 項目 | 内容 |
|---|---|
| Bundle ID ／ 表示名 | `work.ltv.sui` ／ 雀荘 翠 |
| 依存 | `@capacitor/core` `ios` `app` `haptics`（7系）、開発用 `cli` `assets` |
| WebView | `contentInset: never`（本体が `viewport-fit=cover` と `env(safe-area-inset-*)` で切り欠きを避けるため）、`scrollEnabled: false`、背景 `#0a3823` |
| 向き | `Info.plist` を Landscape Left／Right だけに（iPad も同じ＋`UIRequiresFullScreen`）。本体が横画面前提のため |
| 手順 | `npm install` → `sync-web.sh` → `npx cap add ios` → `npx cap sync ios`（`pod install` は UTF-8 の端末が必要。`LANG=en_US.UTF-8` で成功、4 pods）→ `npm run icons` |
| アイコン | 元の 512px アイコンと同じ図柄を SVG で描き直し、headless Chrome で 1024px 全面（透過なし）を出力。スプラッシュ用に牌だけの透過ロゴも |

### 2. スクリーンショット（`tools/screenshots.sh`）

- `index.html` に撮影用の場面 `?shot=home|table|result|story|records` を追加。`&demo=1` で見栄えのする記録（主人公・進み・戦績・実績）をその端末に書き込むので、**空のプロファイルでだけ使う**（スクリプトは一時フォルダのプロファイルを使う）
- 手元の Google Chrome を puppeteer-core（Dropbox の外 `~/.cache/sui-shots` に入れる）で動かし、横向き 3 サイズ（6.7インチ 2796×1290、6.5インチ 2688×1242、5.5インチ 2208×1242）× 5 場面を `ios-app/screenshots/` に出力。CSS の幅×高さに倍率 3 を掛けて実機と同じ大きさにしている。1枚ごとに空の保存領域で開く
- はじめは Chrome の `--headless --screenshot` だけで撮ろうとしたが、このページでは2枚目から止まってしまった（原因未特定）ので puppeteer に切り替えた
- `table` は「リーチ後にあがり牌を引いた場面」（一発・赤ドラ・ドラ・供託2本・1本場）、`result` はその和了画面（立直・一発・門前清自摸和・平和・ドラ2 → 跳満）

### 3. 引き渡し手順（`ios-app/岩崎さんへの引き渡し手順.md`）

共通ルールの8項目に沿って作成。アプリ概要（通信は「オンライン対戦を選んだ時だけ」と明記）、環境、ビルド手順（`npm install` → `LANG=en_US.UTF-8 npm run sync` → workspace を開く）、署名、申請の手順、**申請情報の下書き**（アプリ名・サブタイトル・説明文・キーワード・カテゴリ・年齢制限・プライバシー・URL・審査メモ）、審査で見られやすい点（4.2、横向き、安全域、音）、修正の手順。

### 4. ほか

- 設定画面の版の横に「サポート・プライバシー」（`support.html`）
- `ios-app/node_modules/`（約100MB）は Dropbox を重くするので、生成が終わったら消す（`npm install` で戻る。引き渡し手順にも明記）
