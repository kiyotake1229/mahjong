# 初心者向けの見直し（表記の統一・点数の動き・説明の追加）

- 管理番号: #0042
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）。あわせて紹介ページ・サポートページの表記（WEB）
- 作成日: 2026-10-27
- 関連: #0040・#0041（実際に遊んで見つけた不具合の修正）、#0033（待ちの表示）

## 概要

「麻雀の初心者だと分からない所はあるか」という相談を受け、初めて遊ぶ人の目線で見直した。不具合ではないが、迷いやすい所を8つ直した。

1. 「立直」と「リーチ」の表記が混ざっていた（ボタンは「立直」、案内文は「リーチ」）
2. 流局の画面で点数の増減が分からなかった
3. リーチすると1,000点減る理由の案内がなかった
4. 対局開始のキャラのひとことが、真ん中の案内文に重なっていた
5. 初めての人でも、自由対局のCPUが「ふつう」で始まっていた
6. あがりの画面で、誰が何点払ったかが分からなかった。小さい画面では点数と「次の局へ」が枠の下に隠れていた
7. 案内文が長いと、スマホでは3行目以降が隠れていた
8. 和了画面の「翻・符」「満貫」などの意味が分からなかった

## 対象ファイル

- `index.html`
- `about/index.html`、`support.html`（表記の統一）
- `README.md`

## 変更内容

### 1. 「リーチ」に統一

- ボタンを「リーチ」にした（アイコンも付く。アイコンの対応表は「リーチ」で作ってあり、「立直」では付いていなかった）。選ぶ時の案内「リーチする牌を選ぶ」、自分の番の案内「リーチもできます」、道場の指示（「下のリーチを押そう」、光らせるボタンの指定 `hlBtn('リーチ')`）、「いまの手を見る」の狙える役、ルールブック、画面の見方、戦績の「リーチ率」、道場の説明「リーチ1＋門前ツモ1＋ドラ2」
- 役の一覧（和了画面・待ちの詳細）は正式名を残し「立直（リーチ）」「ダブル立直（ダブルリーチ）」と添える（`yakuLabel`）。役の説明も「リーチのこと。」から始めた。役図鑑の数え方（役の名前）は変えていない
- 途中流局の「四家立直」など、ルールの名前はそのまま

### 2. 流局の画面

- 全員の点数に増減を添えた（「26,500 +1,500」）。「聴牌／不聴」を「テンパイ／ノーテン」にした
- 説明を1行：「テンパイ＝あと1枚であがれる形。テンパイの人が、ノーテンの人から合計3,000点を受け取る。親がテンパイなら親が続く」（全員テンパイ・全員ノーテンの時は「点数の動きはなし」）
- 増減は、点数を動かす前に控えた値（卓の上に増減を一瞬出す `showDeltas` で取っていたもの）との差。オンライン対戦では部屋主が計算して参加者に送る（参加者の端末では、届いた値だけを使う）。途中流局は点数が動かないので出さない

### 3. リーチの1,000点

- 自分がリーチした時に「リーチ棒として1,000点を場に出しました（この局であがった人がもらいます）」と出す。初心者モードの間と、最初の2回（保存キー `mjRiiHint`）。レッスンの中では出さない（レッスンが説明するため）

### 4. 対局開始のひとこと

- キャラのひとことの吹き出しが、真ん中の案内文・待ちの表示に重なる時は、名札の右か左（左右の席は上も）へ移す（向きの三角は消す）
- 移す先が四隅（局の情報・ボタン・順位行）にも重なる時は、そのひとことは出さない（飾りより案内とボタンを優先）。オンラインのひとことチャットは今までどおり出す

### 5. 自由対局の強さ

- まだ自由対局を遊んだことがない人（戦績の対局数が0）で、強さを選んだことがない人は「やさしい」から始める（その場で保存）。以前から遊んでいる人は今までどおり「ふつう」

### 6. あがりの画面

- 「点数の動き　あなた +13,000　ゲン −4,000 …」を、点数が出たあとに出す。ダブロンの時は「この局の点数の動き」（2人分の合計）
- 点数が出る時・演出を飛ばした時・「次の局へ」が出た時に、枠を下まで自動で送る（667×375 では「次の局へ」が枠の下に隠れていた）

### 7. 案内文

- 枠に入らない時は、文字を 92%・85%・78% と小さくして収める（`fitGuide`）。それでも入らない時は今までどおり下をぼかす

### 8. 翻・符と満貫

- 和了画面の「5翻 20符」をタップすると「翻（ハン）＝役とドラの合計…符（フ）＝あがり方や手の形で決まる細かい点…」、「満貫」「跳満」などをタップすると何翻で何点かを出す（`hfDesc`）。点線の下線と、案内「役の名前や「翻・符」をタップすると説明が出ます」

### そのほか

- 版を 2026.10.27 に。「新しくなりました」を更新（新しい4件）
