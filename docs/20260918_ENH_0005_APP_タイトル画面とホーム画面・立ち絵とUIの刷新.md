# タイトル画面とホーム画面・立ち絵とUIの刷新

- 管理番号: #0005
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）。あわせて PWA 設定（manifest.json・sw.js）
- 作成日: 2026-09-18
- 関連: #0004（横画面向けの卓）。#0001 の「画面の流れ」はこの文書の内容に置き換わる

## 概要

利用者から「ゲームとしていきなり雀卓で始まるのは変」「キャラやUIをよくして全体のクオリティを上げたい」と要望があった。
そこで、起動の流れを「タイトル画面 → ホーム画面 → 各モード」に改め、登場人物10人の立ち絵を影絵から顔の見えるイラスト調に描き直した。あわせて、対局中のメニューを簡潔にし、設定を1画面にまとめ、ボタン・窓・カットイン・会話画面の見た目を整えた。
画面案と立ち絵・UI部品は Claude Design のキャンバスにまとめた（下の確認URL）。

## 対象ファイル

- `index.html`（タイトル・ホーム・対局中メニュー・設定の画面、立ち絵の描画、起動の流れ、CSS）
- `manifest.json`（アプリ名と説明を「雀荘 翠」に）
- `sw.js`（キャッシュ名を `mahjong-v7` に更新）
- `README.md`（現在の状態・機能・直近の追加）
- `.claude/launch.json`（手元で確認するときのサーバー設定。アプリの動作には関係しない）

## 変更内容

### 1. 起動の流れ

| 画面 | 中身 |
|---|---|
| タイトル | 「雀荘 翠」のロゴ、夜の街と卓の絵、雨の動き、白・發・中の牌。タップ（Enter／スペースでも可）でホームへ |
| ホーム | 左に「物語」のカード（主人公の名前・出自・次に遊ぶ節・進み具合・担当キャラの立ち絵）。右に「自由対局」「みんなで対戦」「道場」「翠ノート」のカード。下に「ルールブック」「画面の見方」と常連の立ち絵（タップするとひとこと）。上に音・設定・タイトルへのボタン |
| 対局中メニュー | 右上の「メニュー」で開く。対局にもどる／画面の見方／ルールブック／設定／ホームにもどる の5つだけ |
| 設定 | CPUの強さ・おたすけモード・音・赤ドラ・ひとこと・画面の見方・ルールブック・物語を最初から を1画面に |

- 以前は、初回は物語の一覧が卓の上に重なって開き、2回目からはいきなり配牌された卓が出ていた。今は必ずタイトルから始まる
- 招待リンク（`#room=` 付き）で開いた時はホームの上に「みんなで対戦」を開く
- 対局や物語が始まるとホームは自動で閉じる（`newHand`・`rigGame` に入れた）。対局の途中でホームに戻ると、ホームの上に「対局にもどる」（レッスン中は「レッスンにもどる」）が出る
- 物語の一覧（雀荘「翠」の画面）からは、自由対局・対戦・設定の項目を外し、章の一覧と翠ノート・道場・ホームへ に絞った。オンラインの各画面の「メニュー」もホームに戻る
- 縦持ちの「横向きにしてください」は卓が見えている時だけ出す（タイトル・ホーム・会話では出さない）

### 2. 立ち絵の描き直し

- 10人（マスター・ハヤト・シズカ・ゲン・レン・クロダ・堂本・カラス・鷲尾・ミナト）を、顔・髪・服・小物のあるフラットなイラスト調に。線画に2トーンの影。
- 部品（顔の形4種、目・眉・口の型、眼鏡・傷・葉巻・かんざし・ヘッドホンなど）を組み合わせる方式にしたので、人物の追加や表情の追加がしやすい
- ポーズは従来どおり「通常／指さし／腕組み」。会話シーン・コーチの吹き出し・章の一覧・カットイン・ホームで共通の関数（`portraitSVG`）を使う
- 席の色・名札・吹き出しの色（`bg`・`acc`）は以前の値を引き継いだので、既存の画面の色は変わらない

### 3. UIの磨き込み

- ボタンにホバーの持ち上がりとキーボード操作時の枠線。窓の見出しに金の細い線、窓の背景を少しぼかす
- 「○○ 戦」のカットインに相手の立ち絵を出す
- 会話シーンの立ち絵にゆっくり呼吸する動き
- `<title>` と PWA の名前を「雀荘 翠 - 4人打ち麻雀」に（ホーム画面の短い名前「麻雀」は据え置き）

## 確認URL

| 環境 | URL |
|---|---|
| ローカル | http://127.0.0.1:8766/index.html（`.claude/launch.json` のサーバー、または `python3 -m http.server 8766`） |
| 本番 | https://kiyotake1229.github.io/mahjong/ |
| 画面案・立ち絵・UIキット（Claude Design） | https://claude.ai/artifact/18ym42Gd8bKcnsRUMm3R1X |

確認した内容：

- 844×390（iPhone 横）・667×375（iPhone SE 横）・1280×720（PC）・390×844（縦持ち）で、タイトルとホームが崩れないこと
- タイトル → ホーム → 自由対局 → メニュー → ホームにもどる → 対局にもどる の往復
- ホームから 物語（序章 → 第0章の会話で新しい立ち絵）・道場（レッスンのコーチ）・みんなで対戦・設定・ルールブック・画面の見方 を開いて戻れること
- 縦持ちで「横向きにしてください」がホームでは出ず、卓では出ること
- 自由対局を1局進めて、エラーが出ないこと
