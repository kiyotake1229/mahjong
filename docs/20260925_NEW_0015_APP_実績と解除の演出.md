## 概要

続ける目標として実績を28個入れた。戦績（#0014）・道場・物語・翠ノートの進みから判定し、解除した瞬間に画面右上に「実績解除」の帯が出る。一覧は「戦績」画面の「実績」タブ。解除した日付も残る。

- `README.md`

## 変更内容

### 1. 実績の一覧（`ACH`）

| 系統 | 実績 |
|---|---|
| あがり | 初和了／はじめてのリーチ／自力で引く（ツモ）／直撃（ロン）／満貫デビュー／跳満の夜（6翻以上）／役満 |
| 対局 | 一荘目（1回打ち切る）／常連（10回）／翠の主（50回）／初トップ／トップ10回／四万点／六万点／百局 |
| 役図鑑 | 10種／20種／30種 |
| 特殊ルール | 流し満貫／仕切り直し（九種九牌）／責任はとってもらう（責任払いで受け取る）／粘り腰（流局時聴牌5回） |
| ご愛嬌 | 洗礼（飛ばされる）／授業料（30回振り込む） |
| 物語・道場 | 道場皆伝（レッスン全クリア）／腕試し（第二章の第一戦に勝つ）／物語の終わり／翠ノート完成 |

### 2. 判定と保存

- `checkAch()` が未解除の実績を順に調べ、条件を満たしたものを `mjAch` に「解除した日時」で保存し、帯を出す（複数同時なら0.9秒ずつずらす）
- 呼ぶ場所：局の終わり・半荘の終わり（戦績の更新のあと）、レッスンのクリア（道場・物語の教え）、物語の戦の結果、翠ノートにページが増えた時、ホームを描いた時（物語のクリアなど、他の場所で進んだ分をここで拾う）
- 帯（`achBanner`）は右上に固定、メダルのアイコン＋実績名。3.6秒で消える。効果音は既存の選択音

### 3. 画面

- 「戦績」画面に「実績 n/28」タブ。解除済みは金色で日付つき、未解除は灰色（条件は最初から見える）
- 「記録を消す」は実績も一緒に消す（確認あり）
- ホーム下の入口の名前を「戦績・役図鑑・実績」に
