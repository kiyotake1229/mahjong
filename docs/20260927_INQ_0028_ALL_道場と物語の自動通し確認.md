# 道場と物語の自動通し確認（tools/lessons.js）と結果

- 管理番号: #0028
- 種類: INQ（調査・確認）
- 対象: プロジェクト全体（ALL）。`tools/lessons.js`・`tools/soak.js`・`index.html` の進行
- 作成日: 2026-09-27
- 関連: #0024（この仕組みの前身 `tools/soak.js` で見つけた不具合）、#0006・#0008（物語の進行不可の報告）

## 概要

「物語で進めなくなる」という報告（#0008 では再現できず「やり直す」で逃がしていた）を、人が触らずに機械的に洗い出せるようにした。コーチの指示（光っている牌・ボタン）、会話の送り、選択肢、クイズ、結果画面を自動で押して進める道具 `tools/lessons.js` を作り、道場の8レッスン、第0章の3節、第一章の8節（終節の一局を含む）を通した。あわせて `tools/soak.js` に、確認ダイアログで止まらないようにする処理を足した。

## 対象ファイル

- `tools/lessons.js`（新規）、`tools/soak.js`（ダイアログの扱い）、`tools/README.md`

## 内容

### 道具の作り

- 手元の Chrome を puppeteer-core で裏で動かし、`index.html` を読み込んで進行を自動化する
- 押す順番：会話（選択肢があれば最初の選択肢、なければ送る）→ 結果などの画面（「次の局へ」やそれ以外のボタン。「やめる・中断・もどる」は押さない）→ コーチのボタン（クイズは選択肢を順に試す）→ 光っている牌 → 光っているボタン → 「どれでもいいから捨てる」の段は右端の牌
- レッスン以外の自由に打つ場面（練習の一局・終節の一局・戦）は自分の席も自動で打つ（`tools/soak.js` と同じ打ち方）
- 完了の判定：レッスンは `mjLesson_○○`、第0章は `zeroProgress`、第一章は `storyProgress`、戦は結果画面が出たこと
- `confirm` が出ると裏の Chrome は固まるので、内容を記録してキャンセル扱いで閉じる（`soak.js` も同じ）
- 時間内（既定200秒）に終わらない項目と例外を報告。終了コードで成否が分かる

### 結果（2026-09-27）

| 項目 | 結果 |
|---|---|
| 道場 8レッスン（牌のきほん・はじめての和了・リーチとロン・鳴きと守り・役とドラ・フリテン・点数の見方・七対子） | すべて通過（各2〜6秒） |
| 第0章 3節（麻雀って何をするゲーム？・配牌、山、ツモ・あがりの形） | すべて通過 |
| 第一章 8節（入店・初めての和了・早打ちのハヤト・シズカの守り・勝負師ゲン・牌効率・押し引き・終節「翠の一員」） | すべて通過（終節の一局も結果まで） |
| 例外 | なし |

道具の側の直しは3回あった（説明の段で「例」として光る牌を押し続けていた、「どれでもいい」の段で牌を押せなかった、レッスン後の画面で「自由対局」を押して確認が出ていた）。いずれもアプリの不具合ではなく、駆動の作り方の問題。#0024 のリーチの不具合は、これより前の `soak.js` で見つけている。
