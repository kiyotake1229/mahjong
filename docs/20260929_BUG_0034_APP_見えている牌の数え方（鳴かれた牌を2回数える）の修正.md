# 見えている牌の数え方（鳴かれた牌を2回数える）の修正

- 管理番号: #0034
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-29
- 関連: #0031（原因が入った変更）、#0033（この数え方を残り枚数に使う）

## 概要

「自分から見えている牌の枚数」を数える関数 `visibleCounts` が2つあり、#0031（物語 第二部）で足した方が、CPU の押し引きで使っていた元の方を上書きしていた（JavaScript では同じ名前の関数は後に書いた方が有効になる）。後から足した方は、鳴かれた捨て牌を「河」と「鳴いた組」の両方で数えていたため、ポン・チーされた牌が1枚多く見えていた。

影響（2026-09-28 の #0031 から今回まで）：

- CPU（つよい・鬼）の押し引き：危険度の計算で、鳴かれた牌の周りを実際より安全と見ていた（壁＝4枚見えている、字牌の3枚見え、の判定が早く付く）
- 読み筋（主人公のスキル）の危険度の色：同じく鳴かれた牌の周りが少し安全寄りに出ていた
- 点数・役・進行には影響なし

## 対象ファイル

- `index.html`（`visibleCounts`）

## 変更内容

- 関数を1つにまとめ、鳴かれた捨て牌は鳴いた組の方だけで数えるようにした（#0031 より前の数え方と同じ）
- 前にあった方の定義は削除し、どこにまとめたかをコメントで残した
