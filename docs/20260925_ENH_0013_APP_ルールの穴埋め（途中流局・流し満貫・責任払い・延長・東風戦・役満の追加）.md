## 概要

「本格ルール」を名乗るのに足りていなかった決まりごとをまとめて入れた。麻雀アプリとして一般的なもの（途中流局・流し満貫・責任払い・西入・アガリやめ・東風戦・喰いタンの有無）と、数えていなかった役満（大四喜・小四喜・四槓子・緑一色・九蓮宝燈・天和・地和）。それぞれ設定画面の「ルール」であり／なしを選べる（初期値はすべて「あり」、対局の長さは半荘）。

レッスン（道場・物語の教え）、終節の一局、練習の一局では途中流局と流し満貫は使わない（教える手順どおりに進めるため）。物語の戦は設定に関わらず半荘。

## 変更内容

### 1. 途中流局（設定「途中流局」）

親はそのまま続けて1本場、供託はそのまま。画面は「途中流局」と理由を出す（`abortDraw`・`showDraw`）。

| 種類 | 判定 |
|---|---|
| 九種九牌 | 最初のツモの時点（自分の捨て牌なし・鳴きなし）で1・9・字牌が9種類以上あると、手番のボタンに「九種九牌」が出る。押すと流れる。CPUも同じ条件で流す（11種以上で国士が近い時は半々で続ける） |
| 四風連打 | 鳴きなしで4人の最初の捨て牌が同じ風牌。4枚目が通った時点で流れる |
| 四家立直 | 4人目のリーチの捨て牌が通った時点で流れる。リーチ棒は次の局に持ち越し |
| 四槓散了 | 2人以上で合計4回カンし、4回目のカンのあとの捨て牌が通った時点で流れる（1人で4回なら続く）。その捨て牌はロンだけできて、ポン・チーはできない。4回目以降はカンのボタンが出ない |

### 2. 流し満貫（設定「流し満貫」）

流局した時、捨て牌が全部1・9・字牌で、一度も鳴かれていない人は満貫のツモと同じ点（子8000・親12000）を受け取る。その局は聴牌料のやり取りをしない。親の続きは通常どおり聴牌かどうかで決める。流局画面に「流し満貫」の印。

### 3. 責任払い・パオ（設定「責任払い」）

大三元・大四喜を確定させるポン・大明槓をさせた人を記録し（`markPao`、その場で「責任払い」と案内）、その役満であがった時に：ツモなら全額（本場も）、他の人からのロンなら振り込んだ人と半分ずつ（本場は振り込んだ人）。パオの人自身が振り込んだ時は通常どおり。和了画面に「責任払い：○○が全額／と折半」と出る（`paoShares`・`applyWin`）。

### 4. 終局のきまり（設定「延長（西入）」「アガリやめ」「対局の長さ」）

`gameOverAfter` に一本化し、局の終わり（`endCheck`）とオンライン対戦の次局の通知（`netSnapNext`）の両方から使う。

- 対局の長さ：半荘（東・南）か東風戦（東のみ）。対局の始めに `G.len` に固定するので途中で変えても影響しない
- 延長：最後の局が流れた時に誰も30000点に届いていなければ次の場（西入。東風戦は南入）へ。誰かが30000点以上になった局で終わり。延長の4局目が流れたら打ち切り。延長に入る時に案内を出す
- アガリやめ：最後の局で親がただ一人のトップのままあがる、または聴牌で流局すると終局（途中流局では終わらない。延長の条件にかかる時は続く）
- トビ（0点未満）はこれまでどおり

### 5. 役の追加・修正

- 大四喜・小四喜・四槓子（`evaluate`）、緑一色・九蓮宝燈（`addFlags`）、天和・地和（`addExtra`。`buildCtx` が「第一ツモ・鳴きなし」を渡す）
- 暗槓を暗刻に数えていなかったので、三暗刻・四暗刻の判定に含めた
- 喰いタン（設定「喰いタン」）：なしにすると鳴いた断幺九は役にならない
- 役の説明（結果画面でタップ）とルールブックに「特殊ルール」タブを追加

### 6. ほか

- 設定は端末に保存（`mjLen`・`mjAbort`・`mjNagashi`・`mjPao`・`mjExt`・`mjAgariyame`・`mjKuitan`）
- オンライン対戦では部屋主の設定が使われる。参加者の端末には「九種九牌」のボタンは出ない（部屋主の設定が分からないため。次の課題）
- 自動保存（#0009）は途中流局の状態も含めて保存され、再開すると次の局（1本場）から始まる
- 版を 2026.09.25 に

確認した内容：

- 点数ツール：手の検査31件（九蓮宝燈・大四喜・小四喜・四槓子・暗槓入りの四暗刻・緑一色・天和・地和・喰いタン・喰いタンなし→役なし を追加）、責任払いの分担4件、支払いの表34件がすべて一致。以前「清一色＋一気通貫」としていた検査の手は実は九蓮宝燈の形だったので、手を差し替えた
- 九種九牌：仕込んだ配牌で「九種九牌」ボタンが出る → 押すと「途中流局」画面 → 次の局は同じ親で1本場
- 四風連打・四家立直・四槓散了：それぞれの状態を作って打牌を通すと途中流局になる。鳴きが入っている時、風が違う時は流れない
- 流し満貫：捨て牌が全部幺九牌の子が +8000（親 -4000、他の子 -2000）。鳴かれた牌がある人は対象外。聴牌料のやり取りなし
- 責任払い：3つ目の三元牌をポンさせた人が記録され、ツモで全額（本場込み 32300）、他家からのロンで折半（16000 と 16300）、パオの人自身の振り込みは通常どおり
- 終局：南4局が流れて全員30000点未満 → 西1局に進み案内が出る → 31000点の人が出た局で終局。東風戦は東4局で終局。アガリやめ・トビ・同点トップの扱いを含む13通りの判定を確認
- 途中流局の直後に再読み込み → 「続きから」で次の局（1本場）から再開
- 4回のカンのあとはカンの選択肢が出ない
- 設定画面（844×390）に「ルール」7項目が並び切り替えられる。ルールブックに「特殊ルール」タブ
- 通常の局：捨てる → CPUが打ち進む流れに影響なし。コンソールにエラーなし
