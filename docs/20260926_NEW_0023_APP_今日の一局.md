# 今日の一局（日替わりの同じ配牌で1局）

- 管理番号: #0023
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-26
- 関連: #0014（戦績）、#0015（実績に2つ追加）、#0009（自動保存。途中で閉じても再開できる）

## 概要

毎日開く理由を作るため、その日だけの配牌で1局だけ打つ「今日の一局」を入れた。日付から作った種で山を並べるので、同じ日は誰が何度打っても同じ配牌・同じ山（相手の打ち方は毎回変わる）。あなたが親、相手は常連3人（ハヤト・シズカ・ゲン、強さ「ふつう」固定、赤ドラあり固定）。1局が終わった時の点数と25000点の差（収支）を競い、その日のベスト・自己ベスト・連続日数を端末に残す。

## 対象ファイル

- `index.html`
- `README.md`、`support.html`、`ios-app/岩崎さんへの引き渡し手順.md`（実績の数を30に）

## 変更内容

- 入口：ホーム右上の「今日の一局」（挑戦済みなら「今日：+8,000」のように今日のベストを表示）→ 説明と記録の画面（`showDailyIntro`）→「はじめる」
- 配牌：`startDaily` が `DAILY_NEXT`（日付と種）を置き、`newHand` が種つきの乱数（`mulberry32`）で山を並べる。相手と強さ、赤ドラも固定。`G.daily` に日付を持つ
- 終わり：局の終わり（和了・流局・途中流局）の「結果を見る」→ `endCheck` が `dailyEnd` に振り分け、収支を計算して `mjDaily`（今日の日付・回数・今日のベスト・自己ベスト・連続日数・最近30日）を更新し、結果画面（自己ベスト更新の表示、「もう一度（同じ配牌）」「ホームへ」）
- 連続日数：前日に打っていれば +1、それ以外は 1 から。同じ日に何度打っても増えない
- 途中で閉じても自動保存（見出し「今日の一局　東1局」）から再開でき、結果まで進んでいた保存は結果画面へ
- 実績を2つ追加：「今日の一局」（挑戦する）、「七日通い」（7日連続）。実績は30個に
- 戦績（#0014）にはふつうの局として数える
- ついでの小修正：ブラウザ版の振動（#0017）は最初のタップより前に呼ぶとブラウザが拒んでコンソールに警告が出るため、タップ前は呼ばないようにした
