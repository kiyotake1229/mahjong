# 待ちの残り枚数と点数の見込み・順位の条件

- 管理番号: #0033
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-29
- 関連: #0032（待ち牌と順位の表示）、#0034（見えている牌の数え方の修正。残り枚数の計算に使う）

## 概要

#0032 で出した「待ち牌」と「順位と点差」を、打つ判断に使える情報に広げた。

1. 待ち牌ごとの残り枚数
2. あがった時の点数の見込み（ロン・ツモ）と、役がない待ちの警告
3. 待ちの詳細（真ん中の「待ち」をタップ）
4. 順位が入れ替わる条件（右上の順位をタップ）

## 対象ファイル

- `index.html`
- `README.md`

## 変更内容

### 1. 残り枚数

- 残り＝4枚 −（自分の手・全員の河と鳴き・ドラ表示に見えている枚数）。相手の手の中にある分は分からないので数えない
- 初心者モードOFF：卓の真ん中の待ち牌の右下に丸数字。0枚（もう出ない待ち）は赤
- 初心者モードON：案内文に「3萬(残り1)・6萬(残り3)」。自分の番のテンパイの案内と「いまの手を見る」にも付けた

### 2. 点数の見込み

- `waitEst`：待ちごとに、いまの手・鳴き・リーチの有無・ドラで役と点数を計算する（ロンとツモの両方）
- 入れないもの：一発・海底・河底・嶺上・槍槓・天和・地和（その時にしか分からない役）と裏ドラ（見えない情報）。本場と供託も含まない
- 表示：「ロン 1,500　ツモ 700オール」。待ちによって違えば「2,000〜3,900」。一部の待ちだけ役がなければ「一部役なし」、どの待ちも役がなければ「役なし　このままではあがれない」。フリテンは「ロン 不可」
- 初心者モードONの案内文：「あがると ロン 1,500・ツモ 700オール」。門前でリーチしていなくてロンに役がない時は「（リーチすればロンもできる）」
- 同じ手・同じ状況では計算を使い回す（描き直しのたびに計算しない）

### 3. 待ちの詳細

- 真ん中の「待ち」をタップ（キーボードは Enter）で、待ちごとの残り枚数・ロン・ツモの点数と、役の名前・翻・符の表

### 4. 順位の条件

- 右上の順位行をタップで「順位と条件」。全員の着順・点数・自分との差（親の印つき）と、次の条件：
  - 上の人ごとに「抜くには」：ツモ／その人から直撃／ほかの人から
  - 下の人ごとに「抜かれるのは」：その人のツモ／あなたから直撃／ほかの人から
- 計算：符（20〜110）×翻（1〜4）と満貫〜役満の点数を安い順に並べ（`handCands`）、本場（ロンは＋300×本場、ツモは各自＋100×本場）と供託を足して、最初に条件を満たす手を出す（`passCond`）
  - 同点は席順（起家に近い方が上）。最終順位の決め方と同じ
  - 一番安い手で足りる時は「あがれば届く」、役満でも足りない時は「役満でも届かない」
  - 流局の聴牌料は含めない（画面に明記）
- オーラス以外でも開ける（いまの差の目安）

  - 1着を抜く：ツモ 1,300-2,600以上／直撃 3,200以上／ほかから 6,400以上

  - 親に抜かれる：ツモ 800オール以上／あなたから直撃 2,000以上／ほかから 3,400以上
  - 9つとも手計算と一致（同点の扱いを含む。例：親の1,500直撃は同点で席順により届かない）
