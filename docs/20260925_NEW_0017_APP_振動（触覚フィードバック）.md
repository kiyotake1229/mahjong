# 振動（触覚フィードバック）

- 管理番号: #0017
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: iOSアプリ化の準備（App Store ガイドライン 4.2 のネイティブ機能）

## 概要

打牌・鳴き・リーチ・あがり・流局・実績解除で短く振動する。iOSアプリ版では Capacitor の Haptics、Android のブラウザでは `navigator.vibrate`。どちらもない環境（iPhone の Safari、PC）では何も起きない。設定の「あそびやすさ」でON/OFF（初期値ON）。

## 対象ファイル

- `index.html`
- `README.md`

## 変更内容

- `haptic(kind)`：`window.Capacitor.Plugins.Haptics` があれば `impact`（light／medium／heavy）または `notification`（win＝SUCCESS／lose＝ERROR／warn＝WARNING）。なければ `navigator.vibrate` に長さの違うパターン。例外はすべて握りつぶす
- 呼ぶ場所：自分の打牌（light）、鳴き（自分 medium／相手 light）、暗槓・加槓（medium）、リーチ（自分 medium／相手 heavy）、あがり（自分側 win／相手 light、自分の振り込み lose）、流局（medium）、途中流局（warn）、実績解除（medium）
- 設定「振動：ON/OFF」（`mjHaptic`）。切り替えた時に1回振動して試せる
