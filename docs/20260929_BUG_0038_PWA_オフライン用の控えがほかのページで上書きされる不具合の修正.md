# オフライン用の控えが、ほかのページで上書きされる不具合の修正（sw.js）

- 管理番号: #0038
- 種類: BUG（バグ修正）
- 対象: PWA（`sw.js`）
- 作成日: 2026-09-29
- 関連: #0039（紹介ページ。これを出す前に直す必要があった）

## 概要

オフラインで遊ぶための仕組み（Service Worker、`sw.js`）は、ページを開くたびに最新の HTML を取り、アプリ本体の控え（`./index.html`）として保存している。ところが「アプリ本体かどうか」を見ずに、サポートページなど**どのページを開いても**その中身を `./index.html` として保存していた。そのため、サポートページを一度開いたあとにオフラインでアプリを開くと、アプリではなくサポートページが表示された。紹介ページ（#0039）を公開すると、同じことが紹介ページでも起きる。

## 対象ファイル

- `sw.js`

## 変更内容

- アプリ本体（公開先の `/mahjong/` と `/mahjong/index.html`）の時だけ `./index.html` に保存する。ほかのページ（`support.html`・`about/` など）は、そのページのURLで別に保存する
- オフラインの時は、開こうとしたページ自身の控えを出す（アプリ本体は今までどおり `./` の控えにも戻れる）。控えがないページは通信エラーにする
- キャッシュ名を `mahjong-v9` に上げた。新しい版に切り替わる時に、上書きされていた古い控え（v8）は捨てられ、アプリ本体を取り直す

## 確認URL

| 環境 | URL |
|---|---|
| ローカル | 本番と同じ `/mahjong/` の形で `http://[::1]` に置いて確認（`localhost` では登録しない作りのため） |
| 本番 | https://kiyotake1229.github.io/mahjong/ |

確認した内容（手元の Chrome を自動で操作：アプリを開く → 別のページを開く → サーバーを止めてアプリを開く）：

| 別に開いたページ | sw.js | アプリの控えの中身 | オフラインでアプリを開くと |
|---|---|---|---|
| サポートページ | 修正前（v8） | サポートページ | **サポートページが出る** |
| サポートページ | 修正後（v9） | アプリ | アプリが出る（サポートページも別に控えられ、オフラインで開ける） |
| 紹介ページ | 修正前（v8） | 紹介ページ | **紹介ページが出る** |
| 紹介ページ | 修正後（v9） | アプリ | アプリが出る（紹介ページも別に控えられる） |

- ブラウザの「オフライン」指定は Service Worker の通信には効かないため、サーバーを実際に止めて確かめた
