# 対局の自動保存と「続きから」

- 管理番号: #0009
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0005（ホーム画面）、#0008（やり直す）

## 概要

これまでは半荘の途中でアプリを閉じる（画面を消す・ブラウザを閉じる・ホーム画面のアプリを終了する）と、対局が消えていた。スマホは中断が前提なので、ひとり用の対局を自動で端末に保存し、ホームの「続きから」で再開できるようにした。

対象：自由対局、物語の腕試し以降の各戦、終節の一局、練習の一局。
対象外：レッスン（第0章・第一章の教え。節の最初からやり直せば数分で戻れる）、「みんなで対戦」（交代プレイ・オンライン）。

## 対象ファイル

- `index.html`
- `README.md`

## 変更内容

### 1. 自動保存

- 卓を描き直すたび（`render`）に対局の状態（山・手牌・河・点数・親・本場・供託・鳴き・リーチ・物語の戦の情報・スキルゲージ）を `localStorage` の `mjSaveGame` に書く。数KBなので毎回書いても問題ない
- 保存に「自由対局　東2局」のような見出し（`lbl`）と、保存形式の版（`sv`）を付ける。形式が変わった時は古い保存を無視する
- 局の終わり（和了・流局）の直後は、結果画面を閉じる前でも次局に正しく進めるように、勝者と「親が流れるか・本場が増えるか」をその場で記録する（`G._winners`・`G.advance`・`G.keepHonba`。流局では自分が聴牌だったかも記録）

### 2. 再開

- ホームの右上に「続きから（自由対局　東2局）」が出る。押すと卓に戻り、保存した場面から続く
  - 自分の番なら牌を選べる状態、CPUの番ならCPUが続きを打つ、鳴きの確認の途中ならその確認から、局の結果まで進んでいた時は次の局から（終節・練習の一局はその結果の会話へ）
- 保存前に動いていたタイマーが効かないよう、再開時に対局の世代番号を進める

### 3. 保存を消す・上書きを守る

- 半荘の終局、腕試しの結果、終節と練習の一局の結果、「物語を最初から」で保存を消す
- 「自由対局」を新しく始める時と、別の戦を始める時に途中の対局が残っていれば、「途中の対局（○○）を消して始めますか？」と確認する
- 「画面の見方」ツアー用に用意する卓は保存しない。ツアーが終わったら、保存してあった対局に戻る
- レッスンの卓は保存しないので、途中の自由対局を残したまま道場や物語の教えを受けられる

## 確認URL

| 環境 | URL |
|---|---|
| ローカル | http://127.0.0.1:8766/index.html |
| 本番 | https://kiyotake1229.github.io/mahjong/ |

確認した内容：

- 自由対局：CPUの番の途中で再読み込み → ホームに「続きから（自由対局　東1局）」→ 手牌・河・点数・手番が同じ場面から続き、CPUが打ち進めること
- 局の結果画面を閉じずに再読み込み → 再開すると次の局（親の連荘・1本場）から始まり、点数が引き継がれていること
- 腕試しの第一戦（賭けあり）の途中で再読み込み → 「続きから（ハヤト 戦　東1局）」→ 相手の配置・強さ・賭けの有無が同じで、終局すると腕試しの結果画面に進み、保存が消えること
- 練習の一局の途中で再読み込み → 再開でき、局の結果まで進んだ保存から再開すると節の会話に進むこと
- レッスンを始めても保存中の自由対局が上書きされないこと。終局で保存が消えること
