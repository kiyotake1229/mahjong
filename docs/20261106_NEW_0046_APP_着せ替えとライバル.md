## 変更内容

### 1. 着せ替え

- 卓の色6種と牌の背6種（`SKINS`）。色は CSS の変数で切り替える
  - 卓：`--felt`・`--bg0〜2` と、席・真ん中の枠の色（`--pnl`・`--ctrbg`。前は緑みの黒で固定だった）
  - 牌の背：`--bk1`（明るい面）・`--bk2`（暗い面）・`--bkb`（ふち）・`--bks`（影）・`--bkp`（模様）。伏せた牌（`.tile.back`）と相手の手牌の帯（`.backs i`）、背の模様（`backSVG`）がこれを使う
  - テーマごとの変数は `SKINS` の値から `<style>` を作って入れる（色を2か所に書かない）。`body` の `data-felt`／`data-back` で切り替え
- 解放の条件

| 種類 | 名前 | 条件 |
|---|---|---|
| 卓 | 翠 | 最初から |
| 卓 | 藍 | 自由対局で9級になる |
| 卓 | 紅 | 自由対局で1級になる |
| 卓 | 墨 | 自由対局で初段になる |
| 卓 | 夜桜 | 実績を20個解除する |
| 卓 | 琥珀 | 自由対局で五段になる |
| 牌の背 | 翠 | 最初から |
| 牌の背 | 紺 | 今日の1問に5回正解する |
| 牌の背 | 朱 | 役図鑑を15種あつめる |
| 牌の背 | 黒 | 相手のだれかに勝ち越す |
| 牌の背 | 翡翠 | 常連4人みんなに勝ち越す |
| 牌の背 | 金 | 役満であがる |

- 段位は「一度でも届いた一番上」（`STATS.dan.max`）で判定するので、降段しても取り上げない
- 着せ替えの画面（`showSkins`）：卓は小さな卓の絵、牌の背は本物の伏せ牌で見本を出す。まだの物は灰色にして鍵と条件を書く。選ぶとその場で卓に反映（画面の後ろの卓の色が変わる）。ホームの下の「着せ替え」と、設定の一番上から開く
- 新しく解放したら、実績と同じ右上の帯で「着せ替え解放　卓「藍」」と知らせる（`checkSkins`。実績を数えるたびに見る）。今まで遊んでいた人には、初回はいま解放ずみの物を「見た」にするだけで、帯は出さない
- 選んだ物は `mjSkin`、知らせた物は `mjSkinSeen` に保存。記録を消して条件を満たさなくなった物を選んでいたら、翠に戻す
- 右上の帯は同時に2枚まで。多い時は順番に出す（試した時、昇段などで6枚が重なって終局の画面の右半分を隠した）

### 2. ライバル

- 自由対局を打ち終えた時に、相手ごとに「あなたが上の順位なら勝ち」を数える（`rivalApply`。`STATS.riv`）。段位と同じく自由対局だけ
- 3回以上打って勝ちが負けを上回ったら「勝ち越し」。初めて勝ち越した時は、終局のひとことをその相手が言う（常連6人は専用のセリフ `FINAL_LINES.*.rival`。ほかの人は共通の一言）。吹き出しに「はじめて勝ち越し」の札
- 終局の各行の名前の下に「通算 3勝2敗」（初めて勝ち越した相手は金色で「勝ち越し！」）
- 戦績に「ライバル」タブ（`rivHtml`）：相手ごとの顔・打ち方の型・局の記録・勝ち負けとバー・「勝ち越し／五分／負け越し」（3回未満は「まだこれから」）・一度でも勝ち越した印（★）。上に「常連4人への勝ち越し 2 / 4」
- 自由対局の設定の席にも「通算 3勝2敗」

### 3. 実績（35個 → 40個）

- 一級（自由対局で1級）、初段、五段、好敵手（だれかに勝ち越す）、翠の顔（常連4人みんなに勝ち越す）
- 段位・ライバルの実績と着せ替えの解放は、終局の発表が終わってから（約4秒後）帯で知らせる
