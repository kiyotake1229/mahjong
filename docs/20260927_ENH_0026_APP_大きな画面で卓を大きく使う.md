# 大きな画面（iPad）で卓を大きく使う

- 管理番号: #0026
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-27
- 関連: #0004（横画面の卓の配置）、#0019（iOSアプリは iPad にも対応）

## 概要

卓の配置（`fitLayout`）は河の牌 46px・手牌 62px・文字 18px を上限にしていたので、iPad（1024×768、1366×1024）では卓が画面の中央に小さくまとまり、上下に大きな余白ができていた。画面の幅と高さが大きい時だけ上限を最大1.45倍まで広げ、卓が画面いっぱいに使われるようにした。スマホでは倍率が1のまま。

## 対象ファイル

- `index.html`（`fitLayout`）
- `README.md`

## 変更内容

- `kBig = clamp(min(幅/1024, 高さ/720), 1, 1.45)` を計算し、文字の上限（18px）、手牌の上限（62px／大きめ70px）、河の牌の上限（46px）、鳴きの牌（20px）、見出し列の幅（128px）に掛ける。配置の探索はこれまでどおり大きい方から縮めていくので、収まらなければ自然に小さくなる

## 確認URL

| 環境 | URL |
|---|---|
| ローカル | http://127.0.0.1:8766/index.html |
| 本番 | https://kiyotake1229.github.io/mahjong/ |

確認した内容（`?shot=table` の撮影用の場面で）：

- 1366×1024：手牌・河・枠が大きくなり、上下の余白が消える。1024×768 も同様
- 844×390・667×375（スマホ）：倍率1のため配置と大きさが変わらない
- 縦持ち（390×844）はこれまでどおり「横向きにしてください」
