# 第一章 第二節で会話の後に進めなくなる不具合の修正

- 管理番号: #0006
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-18
- 関連: #0005（同じコミットに含む）

## 概要

利用者から「物語の第一章 第二節で進行不可になる」と報告があった。再現すると、第二節「初めての和了」を始めた時、マスターの会話が終わった後に何も表示されず、卓の上で操作できなくなっていた。

## 原因

- 物語の節は `storyStart` が「レッスンの `run()` で卓を用意 → 会話を全画面で表示 → 会話の後にレッスンのイントロ（`tutIntroStep`）を出し直す」の順で動く
- 第二節の `run()`（`startTsumo`）だけは、初回に「画面の見方」ツアーを先に始める作り。ツアーが終わってからイントロ（`tut._intro`）を用意するため、会話が重なった時点ではイントロが無い
- 会話の後の `tutIntroStep` が未定義の `tut._intro` を読んで止まり（コンソールに TypeError）、会話の開始時に隠したコーチの吹き出しも隠れたままになっていた。ツアー済みの端末では起きないため、まったくの初心者（初回）だけが詰まる

## 対象ファイル

- `index.html`（`startTsumo`・`storyStart`・`tutIntroStep`）

## 変更内容

- `startTsumo`：物語から入った時（`storyCasting` 中）はツアーを始めない
- `storyStart`：会話が終わった後に、ツアー未見なら `screenTour(resume)` → レッスンのイントロ、見ていれば直接イントロを出す（README の「第二節の最初に自動で出る」の順番どおりになる）
- `tutIntroStep`：`tut._intro` が無い時は何もしないで戻る（同種の重なりが起きても止まらない）

確認した内容：

- ツアー済みの状態でも同じ節が通ること。道場の「初あがり」（物語を通らない入口）はこれまでどおりツアーから始まること
