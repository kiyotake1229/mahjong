## 変更内容

ページの構成（アプリと同じ深緑と金の配色。スマホ幅でも1列で読める）：

1. アプリについて：遊び方の種類、ルール、記録、通信の有無、料金の表
2. はじめ方：はじめての人／ルールを知っている人／スマホで遊ぶ（ホーム画面に追加）／別の端末に引き継ぐ
3. よくある質問（9件）：横向きにならない、記録が消えた、途中で閉じた、オンラインがつながらない、音が出ない、振動しない、CPUの強さ、点数のルール、不具合の連絡
4. プライバシーポリシー：収集する情報はなし／端末に保存する情報／「みんなで対戦」のオンラインを使う時だけ発生する通信（PeerJS の仲介 0.peerjs.com、相手の端末との直接通信、中継 turn.peerjs.com または利用者が設定した中継、cdnjs からの読み込み）／引き継ぎコード／子ども／変更。制定日 2026-09-25
5. お問い合わせ：提供 ltv.work、メール ai@ltv.work、アプリのURL

書いた内容の根拠は `README.md` の「オンライン対戦の仕組み」。アプリは通信を伴うモードがあるので、「通信なし」とは書かず、いつ・どこに・何が渡るかを具体的に書いた。
