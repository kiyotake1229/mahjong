# 結末の回想（翠ノートから見た結末をもう一度見る）

- 管理番号: #0029
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-28
- 関連: #0028（物語の通し確認。結末まで自動で通す中で、見返す手段がないことに気づいた）

## 概要

物語の結末は6つ（閉店・新しい翠・翠の頂・翠の主・黒い手、払う・白い塔、崩れる）あり、見た結末は翠ノートにページとして残るが、会話そのものを見返す手段がなかった。翠ノートの結末のページに「結末をもう一度見る」を付け、その結末の会話（第四章はエピローグ込み）を再生できるようにした。進み・称号・記録は変えない。

## 対象ファイル

- `index.html`（`showNotes`・`endingLines`・`replayEnding`）
- `README.md`

## 変更内容

- `endingLines(key)`：第四章の結末（`ENDINGS`＋`EPILOGUE`）、第五章の結末（`ST.domoto2` の勝利の会話＋`DARK_END`）、第六章の結末（`ST.washio` の勝利の会話＋結末の会話）を取り出す
- `replayEnding(key)`：会話を再生し、終わったら翠ノートに戻る。主人公の名前や出自による台詞の出し分けは通常と同じ
- 翠ノートで、開いている結末のページだけにボタンを出す

## 確認URL

| 環境 | URL |

| ローカル | http://127.0.0.1:8766/index.html |

確認した内容：

- 結末のページを開いた状態にして翠ノートを開くと「結末をもう一度見る」が出て、押すと会話が始まり、送っていくと翠ノートに戻る。進み（`mjStage`）と称号は変わらない
- 開いていない結末のページにはボタンが出ない
- 6つの結末すべてで会話の行が取り出せる（第四章4つ・第五章・第六章）
