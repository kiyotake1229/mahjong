# 役満に通常の役やドラが混ざって数えられる不具合の修正

- 管理番号: #0012
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0011（突き合わせツールで検出）

## 概要

四暗刻・大三元・字一色・清老頭などの役満があがった時に、対々和・門前清自摸和・役牌・ドラなどの通常の役も一緒に数え、和了画面に「四暗刻 対々和 門前清自摸和 16翻」のように出ていた。点数は13翻以上で役満として払われるので金額は正しかったが、表示が誤り。国士無双だけは以前から役満のみだった。

## 対象ファイル

- `index.html`（`evaluate`）

## 変更内容

- `onlyYakuman(y)` を足し、役の一覧に13翻以上（役満）があれば役満だけを残す。通常の分解と七対子（字一色）の両方で通す
- 数え役満（通常の役で13翻以上）は役満扱いのままで変わらない

## 確認URL

| 環境 | URL |
|---|---|
| ローカル | `node tools/scoring_check.js` |
| 本番 | https://kiyotake1229.github.io/mahjong/ |

確認した内容：

- 四暗刻単騎ツモ → 「四暗刻」だけ13翻。大三元（鳴き）ロン → 「大三元」だけ。字一色の七対子 → 「字一色」だけ。国士無双はこれまでどおり
- 通常の手（平和・断幺・三色 など）の翻・符は変わらないこと（ツールの他の項目がすべて一致）
