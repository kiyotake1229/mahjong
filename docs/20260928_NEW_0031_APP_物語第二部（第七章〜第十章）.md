## 概要

構想（#0030）どおり、第六章のあとに続く第二部をまとめて入れた。主人公は翠の若い主として弟子ナオを教え、街の雀荘対抗戦に二人一組で出て、隣町の雀荘「翡翠」の主・八雲と二十年前の因縁に向き合い、翠杯の決勝でマスターから店を継ぐまで。結末は3つで、いずれも翠が続き、登場人物は退場せず、最後に「全国の対抗戦の招待状」と「見知らぬ客」で次へ繋ぐ。

第二部は第六章をクリアした端末（`mjStage` ≥ 13）で「第七章　弟子 ―第二部―」として開く。第一部の結末がどれでも始められる。

### 1. 仕組み（物語エンジンの拡張）

| 仕組み | 中身 | 使う場所 |
|---|---|---|
| 教える段（`teach`） | 道場の説明・クイズの部品（`infoRun`・`renderQuiz`）を、ナオの手牌を出して主人公が答える形で使う（`runTeach`）。終わると進みを記録し、必要ならスキルを付ける | 第七章 一〜三の教え、第十章 最後の一言 |
| 場面＋選択（`choice`） | 会話のあとに選択肢を出し、結果を `HERO` に持たせる（`runChoice`） | 第八章 相棒（`HERO.partner`）、誘い（`HERO.pro`） |
| 東風の戦（`len:'ton'`） | 戦の長さを東風にできる | 第七章 弟子との一局 |
| 状況スタート（`start`） | 局・親・点数を差し替えて途中から始める（`applyStart`）。`passRank` で「○着以内で突破」 | 第九章 南三局・オーラス |
| 団体戦（`team`） | 自分＋対面 対 上家＋下家。結果は二人の合計点。ボスの席を上家に（`bossSeat`）。配役は関数にして相棒を差し込む | 第八章 一・二回戦、第十章 代表決定戦・決勝 |
| 賭けなしの流儀（`noWager`） | 条件を満たせば賭けなしでも秘密が開く（第二部は賭けを使わない） | 第二部の戦すべて |
| 第二部の結末（`p2final`／`showP2Ending`） | 負け＝「もう一度、翠杯」。勝ち＝第二部の秘密6つ以上＋第一部の結末（翠の主／守り手／灯）を持っていれば「灯を継ぐ」（プロ試験を受けていれば「旅立ち」）、それ以外は「二つの翠」。エピローグは3つ共通＋出自ごとの一行 | 第十章 決勝 |
| 読み筋 | 三の教えで覚える受け身のスキル。リーチ者がいる時、自分の手牌に危険度の印（緑＝現物・通った牌、黄＝スジ・壁、赤＝危険）。CPU の守りの判定（`dangerOf`）をそのまま表示に使う | 第二部以降のすべての対局 |
| 相手の手帳 | 同じ相手との局数・リーチ率・鳴き率・和了率を貯め（`STATS.vs`）、相手えらびに出す | 自由対局 |
| 場所 | 翡翠・商店街会館・市民病院前の背景と音楽の割り当て、章の一覧（第七〜第十章）、見出し（`STAGE_LABELS`）、やり直し時の消去 | ― |
