# リーチ宣言で例外が出て局が進まなくなる不具合の修正

- 管理番号: #0024
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-26
- 関連: #0006・#0008（物語の進行不可。再現できずに「やり直す」を用意していた件）、#0013〜#0023 の総点検

## 概要

自分（画面の人）が「立直」ボタンを押してから牌を捨てると、`humanDiscard` の中でフリテンリーチの案内を出す行が、上のブロックの中でだけ定義した変数 `r` を参照していて `ReferenceError` になっていた。例外で打牌が止まるため、リーチを宣言した瞬間に局が進まなくなる（もう一度牌を押すと、リーチにならずに普通に捨てられる）。2026-09-15 の「みんなで対戦」の改修（`c2ecaf2`）で `humanDiscard` を組み替えた時に入り、以来ブラウザ版のリーチ宣言はすべてこの状態だった。物語の教えでリーチを宣言する場面でも起きるので、#0006・#0008 で追っていた「物語で進めなくなる」報告の正体はこれと考えられる。

見つけたのは、#0013〜#0023 をまとめて確かめるために回した自動の連続対局（自分の席も自動で打ち、リーチ・鳴きを混ぜる）で、リーチ宣言の直後に例外が記録されたため。

## 対象ファイル

- `index.html`（`humanDiscard`）
- `README.md`

## 変更内容

- リーチ宣言の分岐で、宣言牌を除いた手牌 `r2` をその場で作ってフリテンの判定に使う（1行）
- CPU のリーチ（`cpuTurn`）と通信相手のリーチ（`seatDiscard`）は別の経路で、影響なし

## 確認URL

| 環境 | URL |
|---|---|
| ローカル | http://127.0.0.1:8766/index.html |
| 本番 | https://kiyotake1229.github.io/mahjong/ |

確認した内容：

- 修正前：自動の連続対局で、自分の席がリーチを宣言した直後に `ReferenceError: r is not defined` が出て、その局が止まる（4局目で停止）
- 修正後：「立直」ボタン → 牌を捨てる → リーチが成立（リーチ棒1本・1000点減・宣言牌が横）。例外なし
- 修正後の自動の連続対局（`tools/soak.js`、4卓×4分）：110局・8半荘（リーチ14回、鳴き111回、途中流局2回）を通して例外なし。毎局の終わりに「牌の総数が136枚」「点数の合計＋供託＝100000」が保たれた
- 道場「リーチとロン」のレッスンを、コーチの指示どおりに自動で押していく方法で最後まで通した（次へ → はじめる → 牌 → 立直 → 牌 → ロン → クリア）。修正前はこの「立直 → 牌」で止まっていた
