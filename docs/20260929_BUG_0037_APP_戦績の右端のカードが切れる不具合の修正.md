# 戦績の右端のカードが切れる不具合の修正（App Store 用の画面写真の撮り直しを含む）

- 管理番号: #0037
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）、iOSアプリの申請素材（`ios-app/screenshots/`）
- 作成日: 2026-09-29
- 関連: #0014（戦績と役図鑑。原因が入った変更）

## 概要

「戦績・役図鑑・実績」の画面で、統計のカード（対局数・平均順位・1位率・トビ など）の右端の列が枠の外にはみ出して切れていた。横向きのスマホと PC で起きていた（2026-09-25 の #0014 から）。App Store 用に撮った戦績の写真（2026-09-26）にも同じ切れが写っていた。

原因：戦績の中身の幅を「画面幅の88%、最大520px」にしていたが、入れ物の枠（`#modal`）は最大520px の中に左右の余白（26px ずつ、横向きの低い画面では 20px ずつ）と枠線を含むため、中身が枠の内側より 42〜54px 広かった。さらにスクロールバーが出ると、その分（約10px）も足りなくなっていた。

## 対象ファイル

- `index.html`（CSS の `.rb.rc`）
- `ios-app/screenshots/*.png`（撮り直し）

## 変更内容

- 戦績の中身の幅を「枠の内側の幅」に合わせた：最大 466px（余白 26px の時）、横向きの低い画面では最大 478px（余白 20px の時）
- `max-width:100%` を足し、スクロールバーが出ても枠の内側に収まるようにした
- `bash tools/screenshots.sh` で App Store 用の画面写真（3サイズ × 5場面）を撮り直した。戦績の切れがなくなり、実績の数も今の 35 個になった（前の写真は「実績 17/28」）
