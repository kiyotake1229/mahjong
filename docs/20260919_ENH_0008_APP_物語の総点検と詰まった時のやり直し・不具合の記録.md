# 物語の総点検と、詰まった時の「やり直す」・不具合の記録

- 管理番号: #0008
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-19
- 関連: #0006（第一章 第二節の進行不可）

## 概要

利用者から「物語で進行不可になることがまだある（#0006 とは別）」と報告があった。場所の指定がなかったので、物語を最初から最後まで自動操作で3周して調べた。
3周とも止まる箇所・エラーは出なかった（詳細は下の「確認した内容」）。再現できなかったため、万一詰まった時に利用者が自分で抜けられる「やり直す」と、原因を特定するための「不具合の記録」をアプリに入れた。

## 対象ファイル

- `index.html`
- `README.md`

## 変更内容

### 1. 対局中メニューに「この節をやり直す」

- 右上の「メニュー」に、いま遊んでいるものに応じて「この節をやり直す」「この戦をやり直す」「練習の一局をやり直す」「このレッスンをやり直す」が出る
- 押すと確認の後、動いている手番を止めて、その節・戦・レッスンを最初から始める。進み具合（クリア済みの記録）は消えない
- 対象：第0章の節、第一章の節（レッスン）、練習の一局、終節の一局、腕試し以降の各戦、道場のレッスン

### 2. 不具合の記録（設定 → 「不具合の記録」）

- アプリの中でエラーが起きた時に、時刻・内容・場所（行番号）・その時の画面（会話／卓／窓）・節や戦・手番・版を、この端末の中だけに残す（最新8件。外には送らない）
- エラーが起きた瞬間は「エラーが起きました。進めない時は右上のメニュー →「やり直す」」と短く知らせる（30秒に1回まで）
- 設定画面の「不具合の記録」で一覧を見られ、「コピー」で内容（版・端末情報つき）をクリップボードに写せる。「消す」で空にする。設定画面に版（2026.09.19）も表示

### 3. 見張り（詰まりの検知）

- 5秒ごとに次を見て、当てはまれば「進めなくなった時は、右上のメニュー →「やり直す」」と知らせ、不具合の記録にも残す（2分に1回まで）
  - レッスン中に、案内の吹き出しが消えたまま・押せるボタンも光る牌もない状態が25秒続いた
  - 対局中に、CPUの手番のまま局面が40秒動かなかった
- 会話・窓・ホーム・タイトルが出ている間は見ない

確認した内容：

- 物語の自動通し（自動操作の台本で、会話送り・選択・コーチのボタン・光る牌・結果画面を順に押し、15秒以上画面が変わらなければ記録する）
  - 1周目：学生／賭けを受ける／翠を守る道。第0章 → 第一章（練習の一局あり）→ 第二章 → 岐路 → 第四戦 → 最終戦（結末「翠の頂」）→ 第五章 → 第六章（称号「翠の灯」）
  - 2周目：元ギャンブラー／賭けを流す／新しい翠の道／練習は飛ばす／各戦を一度負けてからやり直す。結末「閉店」→ やり直し →「新しい翠」、黒い手のバッドエンドと「あの日に戻る」、白い塔まで
  - 3周目：チェーンの新人／賭けを受ける／実戦形式（山を短くせず、リーチ・ポン・チー・カン・スキルを実際に使い、CPUの和了・自分のロンとツモを含む）。流儀を満たして秘密とスキルを託される流れ、真エンド「翠の主」、二度目の突破の幕間（3戦）
  - 3周とも停止・エラーなし。1周目の途中で見つかった「終節は1局で流局すると負け扱い」は仕様どおり（もう一度／雀荘へ が出る）
- スマホ横（844×390・667×375）と縦（390×844）で、コーチの吹き出し・クイズの選択肢・会話の選択肢・序章のボタンが画面内にあり押せること
- 「この節をやり直す」で第一章 第三節が会話から始まり直すこと。わざとエラーを起こして、知らせが出て記録に残り、設定から見られること。自由対局とレッスンを放置しても見張りが誤って知らせないこと
