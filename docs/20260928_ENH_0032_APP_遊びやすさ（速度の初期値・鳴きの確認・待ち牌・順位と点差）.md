# 遊びやすさの改善（速度の初期値・鳴きの確認・待ち牌とフリテン・順位と点差）

- 管理番号: #0032
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-28
- 関連: #0010（打ち方の設定）、#0004（横画面の卓）

## 概要

「麻雀を遊ぶ時に不便なところ」を洗い出し、4つ直した。

1. 対局速度の初期値が「じっくり」で、慣れた人には遅かった → 初期値を「標準」に。速度を自分で選ぶまでは、レッスン（道場・第0章・物語の教え）だけ「じっくり」のまま
2. ポン・チーができるたびに確認が出て止まる（設定は「毎回出す／全部出さない」の2択だけ）→ 役の見込みがある時だけ聞く「役あり時」を初期値にし、確認のボタンに「この局は鳴かない」を足した
3. 待ち牌とフリテンは初心者モードの案内文にしか出ず、しかも自分の番の間だけだった → テンパイしている間ずっと出す（初心者モードOFFでは卓の真ん中、ONでは案内文の中）
4. 順位と点差が卓上に出ず、オーラスで何点差か分からなかった → 右上のボタンの下に「2着　1着まで 6,000」のように出す。最後の局は「オーラス」、延長中は「延長」の印

## 変更内容

### 1. 速度の初期値

- `SPEED` の初期値を `'normal'`（標準）に。`mjSpeed` が保存されていない（速度を自分で選んだことがない）間は、`sp()` がレッスン中（`G.tutorial`）だけ「じっくり」を返す
- 速度ボタンの表示は `sp()` の値に合わせる（レッスン中は「じっくり」と出る）。押した時は表示中の速度から次へ進める
- 既に速度を選んでいる人には影響なし

### 2. 鳴きの確認

- 設定「鳴きの確認」を3択に：役あり時（初期値）／毎回／出さない。保存キー `mjCallAsk`。以前の「出さない」（`mjNoCall=1`）は「出さない」に引き継ぐ
- 「役あり時」の判定 `callHasYaku`：鳴いたあとに次のどれかが見込めるか
  - 役牌（鳴く牌が役牌／手に役牌の対子・暗刻がある）
  - 断幺九（喰いタンありの時。鳴く牌と組が2〜8で、手に残る1・9・字牌が1枚以下）
  - 混一色・清一色（鳴く牌の色＋字牌が10枚以上）
  - 対々和（ポンで、まだ順子を鳴いておらず、手に対子・刻子が3組以上）
  - すでに鳴いている手は常に聞く（役を決めて鳴き始めた手を止めない）
  - 三色・チャンタ・一気通貫などは判定しない。狙う人は設定を「毎回」に（設定画面にその旨を書いた）
- ポン・チーの確認に「この局は鳴かない」ボタン。押すとその局はポン・チー（大明槓）の確認を出さない。ロンは聞く。局が変わると元に戻る。席ごと（`G.noCall[pid]`）なので、交代で遊ぶ時も人ごとに効く
- どちらもレッスン中とオンラインの参加者（部屋主側で判定）には適用しない。これまでどおり

### 3. 待ち牌とフリテン

- `myWaitInfo(p)`：13枚の形（引いた直後は引いた牌を除いた形）がテンパイなら待ち牌と、フリテンかどうか（自分の河に待ち牌がある／リーチ後の見逃し／同巡の見逃し）
- 初心者モードOFF：卓の真ん中の直前の捨て牌の横に「待ち ［牌］［牌］ フリテン」（`#mystat`）
- 初心者モードON：案内文の「相手の番です…」「リーチ中…」に「テンパイ中　待ち: 三萬・六萬　フリテン（ロン不可・ツモはOK）」を足す（自分の番の案内には以前からある）
- 設定「待ち牌の表示」ON/OFF（初期値ON。保存キー `mjWaits`）。レッスン中は出さない（教える内容と重なるため）

### 4. 順位と点差

- 右上のボタンの下に `#rankLine`：「2着　1着まで 6,000」／トップなら「1着　2着と 6,000差」。同点は起家に近い方が上（席順）
- 最後の局（半荘は南4局、東風戦は東4局）は「オーラス」、延長中は「延長」の印を先頭に
- レッスン・練習の一局・今日の一局では出さない
- 置き場所を右上にした理由：左上の局の情報に3行目として足すと、844×390 で上段の高さが 109.8→119px になり河の牌が 22→20.5px に縮んだ。右上のボタンの下は高さに余裕があり、牌の大きさは変わらない（計測して確認）
- `fitLayout` に「左上の中身がそのまま入る高さ」を上段の下限として足した（今回の変更では効かないが、はみ出しの保険）

確認した内容（ブラウザ 844×390、ミュート手順のうえで）：

- 保存のない状態で開くと `SPEED='normal'`、速度ボタンは「標準」。レッスン中は表示・実効とも「じっくり」。ボタンを押すと標準→はやい
- 鳴きの確認：役なしのポン（9筒で断幺九にならない）は確認が出ず、役ありのポン（5筒で断幺九の見込み）は「ポン／スルー／この局は鳴かない」が出る。チーも同様（1萬は出ず、5萬は出る）。「この局は鳴かない」を押すと `G.noCall[0]=true` になり、同じ局の次のポンは確認なしで進む
- 待ち牌：テンパイの手で真ん中に「待ち 三萬 六萬」、3萬を自分で捨てると「フリテン」の札。初心者モードONでは真ん中には出ず、案内文に「テンパイ中　待ち: 3萬・6萬　フリテン（ロン不可・ツモはOK）」
- 順位：点数 25000/31000/22000/22000 で「2着　1着まで 6,000」、南4局で「オーラス」の印、トップにすると「1着　2着と 6,000差」。順位行の有無で `--pHt`・`--rw` が変わらないことを計測
- 設定画面：3択の切り替えと保存（`mjCallAsk`）、待ち牌の表示のON/OFFと保存（`mjWaits`）
- `node tools/scoring_check.js` すべて一致、`node tools/soak.js 2 2`（38局・3半荘）例外0・不変条件の破れ0、`node tools/lessons.js` 道場8・第0章3節・第一章の通し確認すべて通過（1回目の全項目通しでは終節だけ200秒で終わらなかったが、終節単体（8秒）と全項目の再実行（19項目）はすべて通過。修正前の版でも終節単体は通り、全項目通しは終節の途中で自動操作ツール側の headless Chrome が閉じて（Target closed）比較できなかった。終節の項目は全項目通しの終盤で不安定になることがあり、今回の変更との関係は認められない）
