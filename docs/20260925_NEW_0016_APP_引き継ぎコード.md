# 引き継ぎコード（端末の記録の書き出しと読み込み）

- 管理番号: #0016
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0009（自動保存。途中の対局は引き継ぎに含めない）、#0014・#0015（戦績・実績も引き継ぐ）

## 概要

記録はすべて端末の中（`localStorage`）にあるので、機種変更やブラウザ版からアプリ版（iOS）への移行で消えてしまう。そこで、物語の進み・戦績・実績・設定を1つの文字列（引き継ぎコード）にまとめて書き出し、別の端末で貼って読み込めるようにした。サーバーは使わない（コードは利用者が自分でコピー・共有する）。

## 対象ファイル

- `index.html`
- `README.md`

## 変更内容

- 設定画面の下の段に「引き継ぎ」。押すと `showXfer` の画面
  - 「コードを作る」：`mj` で始まる保存項目をまとめて JSON にし、UTF-8 → Base64 にして `SUI1.` を頭に付ける（`xferMake`）。項目数と文字数を表示
  - 「コピー」：クリップボードへ。使えない環境では全選択して案内。「共有」：`navigator.share` がある端末だけ表示
  - 「読み込む」：貼ったコードを `xferParse` で検査（頭の `SUI1.`、Base64 と JSON の形、版 `v:1`、項目名が `mj` で始まる文字列だけ）→ 上書きの確認 → 保存して画面を読み直す
- 含めないもの（`XFER_SKIP`）：途中の対局（`mjSaveGame`）、不具合の記録（`mjErrLog`）、中継サーバーの設定（`mjIce`。認証情報を含むため）
- 壊れたコード・別アプリのコードは理由つきのメッセージだけで、何も変えない

確認した内容：

- 「コードを作る」→ `SUI1.` で始まるコードができ、戦績・主人公・設定など全項目が入り、途中の対局と中継サーバーの設定は入らない。読み戻すと戦績の中身が一致する
- 「hello」「SUI1.@@@」「版が違う JSON」を貼ると、それぞれ違う理由のメッセージが出て何も変わらない
- 許可していない項目名・文字列でない値・除外項目を混ぜたコードを読み込んでも、許可した項目だけが書き込まれる
- 設定画面（844×390）から開いて戻れる。コンソールにエラーなし
