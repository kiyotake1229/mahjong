# 自由対局の相手えらび（指名・おまかせ・強さ・長さ）

- 管理番号: #0021
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-26
- 関連: #0005（ホーム画面）、#0013（東風戦の設定）

## 概要

これまで「自由対局」を押すと、常連からランダムに選ばれた3人とすぐ対局が始まった。物語で出会った相手（レン・クロダ・堂本・カラス・鷲尾・ミナトなど）と打ちたい、苦手な相手と練習したい、という遊び方ができるように、始める前に相手を指名できる画面を入れた。CPUの強さと対局の長さ（半荘／東風戦）もここで選べる。

## 対象ファイル

- `index.html`
- `README.md`

## 変更内容

- ホームの「自由対局」→ 相手えらびの画面（`showFreeSetup`）
  - 下家・対面・上家の3枠。枠をタップすると、えらべる相手の中で次の人に入れ替わる（他の枠と同じ人にはならない）
  - 「おまかせ」（毎回ランダム）／「指名する」の切り替え。指名は端末に保存（`mjFreeCast`）し、次回も同じ相手
  - CPUの強さ（やさしい〜鬼）と対局の長さ（半荘／東風戦）。設定画面と同じ値を共有
  - 「はじめる」で従来どおり `startFreeGame`（途中の対局があれば確認）
- えらべる相手（`freeCastPool`）：常連4人（マスター・ハヤト・シズカ・ゲン）＋物語で出会った人（次に戦う相手まで。腕試し第一戦の頃からレン・クロダ）。物語を進めると増える
- 局の配役（`newHand`）は `freeCastPick`：指名が有効ならその3人、なければ、えらべる相手からランダム
- ホームのカードに現在の設定（相手／長さ／CPUの強さ）を表示
