# 局のふりかえり（全員の手牌・待ち・打牌の流れ）

- 管理番号: #0020
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-26
- 関連: #0014（戦績）。初心者向けアプリとして「なぜ振り込んだか」「相手は何を待っていたか」を見せるため

## 概要

局が終わった時（和了・流局・途中流局）に、4人全員の手牌と鳴き、聴牌していた人の待ち牌、リーチ・フリテンの印、あがった人の役、そしてその局の打牌の流れ（誰が何を切り、どこでリーチ・鳴きがあったか）を1画面にまとめて見られるようにした。和了画面・流局画面の「この局のふりかえり」から開き、次の局の途中でもメニューの「前の局のふりかえり」で見返せる。

対象：ひとり用の対局と「この端末で交代」。オンライン対戦では出さない（参加者の端末には他の人の手牌が届いていないため）。レッスンでも出さない。

## 対象ファイル

- `index.html`
- `tools/scoring_check.js`（読み込み時の小さな修正）
- `README.md`

## 変更内容

- 局の記録 `G.log`：打牌（リーチ宣言かどうか付き）、ポン・チー・カン（誰から）、暗槓・加槓を、起きた順に積む（`logEv`）
- 局の終わりに `buildReview` が全員分をまとめる：手牌（あがった人は和了牌込みで印）、鳴き、聴牌かどうか（`shanten`）、待ち牌（`waits`）、フリテン、リーチ、点数、あがった人の役と翻・符。結果の一行（「あなた ツモ　7翻 跳満」「流局　流し満貫：○○」「途中流局（四風連打）」）、ドラ表示、裏ドラ表示（リーチであがった人がいる時だけ）
- 画面 `showReview`：結果画面の上に重ねる専用の層（`#review`）。閉じると元の結果画面がそのまま残る。人ごとの枠に印（和了・聴牌・不聴・リーチ・フリテン）と手牌、待ち、役。下に「打牌の流れ」を、切った人の頭文字（席の色）＋牌のチップで並べ、リーチは赤、鳴きは金の枠
- 入口：和了画面の手牌の下、流局画面のボタンの上、対局中のメニュー（`REVIEW_LAST`）
- `tools/scoring_check.js`：撮影用の場面（#0019）が使う `URLSearchParams` を読み込み用の器に追加（読み込み時の例外表示を消す）
