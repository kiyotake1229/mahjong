# 横画面向けの卓と捨て牌の見やすさ

- 管理番号: #0004
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）。あわせて PWA 設定（manifest.json・sw.js）
- 作成日: 2026-09-18
- 関連: #0001（現状の仕様と構成。卓の画面はこの文書の内容に置き換わった）

## 概要

利用者から2つの要望があった。1つは「スマホの横画面用のアプリにしたい」、もう1つは「捨て牌の表示がわかりにくい」。そこで卓の画面を横画面向けに作り直した。捨て牌は、席ごとの枠に全部正位置で並べるようにした。あわせて、直前の捨て牌、リーチ、鳴き、手番を印で示すようにした。

## 対象ファイル

- `index.html`（卓の画面の HTML・CSS・描画の処理）
- `manifest.json`（画面の向きを `landscape` に）
- `sw.js`（キャッシュ名を `mahjong-v6` に更新。古い manifest を掴まないように）
- `README.md`（現在の状態・機能・直近の追加）

## 変更内容

### 1. 画面の組み方（横画面）

| 場所 | 中身 |
|---|---|
| 左上 | 局の情報（局・本場・供託・残り枚数・ドラ表示）とスキル |
| 右上 | メニュー・新局（オンライン中は「ひとこと」）・速度・初心者モード |
| 上・左・右・下の枠 | 4人それぞれの枠。名前・風・点数、印（親・手番・リーチ）、鳴いた組、残りの手牌の数、捨て牌 |
| 真ん中 | 直前に捨てられた牌を大きく表示し、誰が捨てたかを矢印と色で示す。その横に「今やること」（初心者モード） |
| 下の帯 | 自分の手牌と鳴いた組。ボタンは右端（狭い画面では手牌の上に浮かせる） |

- 上の帯（旧 #topbar）はやめて、四隅に分けた
- 牌の大きさは画面の幅と高さ、ノッチの余白、捨て牌の枚数から計算して CSS 変数で渡す（`fitLayout`）
- 描いた後に枠からはみ出していたら、捨て牌を1pxずつ小さくして収める（`fitCheck`）
- 画面の回転・大きさの変化では、大きさだけ計算し直す（描き直さないので、チュートリアルで光らせた場所は残る）

### 2. 捨て牌の見やすさ

- 捨て牌は全部正位置で並べる。以前は左右の人の捨て牌を横倒しにしていたが、読みにくかったのでやめた
- 左から右、上の段から下の段へ並べる。段の頭には何枚目かを小さく出す（1・7・13）
- 直前の捨て牌には金色の枠と「今」の札を付ける
- 手番の人の枠を光らせ、次に牌が置かれる場所を点線で示す
- リーチ宣言牌は横向きにし、赤い線を付ける
- 鳴かれた牌は薄く表示し、鳴いた人の色の矢印を付ける。鳴かれた牌に「誰が鳴いたか」を記録するようにした
- 席ごとに色を決め、枠・真ん中の矢印・ひとことの吹き出しで同じ色を使う
- 鳴いた組の横向きの牌は、鳴いた相手の向きで置く（上家から＝左端、対面から＝真ん中、下家から＝右端。チーは鳴いた牌を左端）

### 3. 縦持ち・ほかの画面

- 縦持ちのスマホでは「スマホを横向きにしてください」を出す。「このまま縦で遊ぶ」を押すと、そのセッションは縦向きの配置（枠を縦に積む）で遊べる
- ホーム画面から開くアプリ（Android）では、最初に触った時に横向きに固定する。iPhone は OS の回転に従う
- 背の低い横画面では、結果画面・会話シーン・コーチの吹き出しを詰めた
- コーチの吹き出しは、光らせた場所と重なりの少ない側（上か下）に出す
- 画面の見方ツアーと第0章の説明を、新しい画面の場所に合わせた。「真ん中に積んである山」とあった説明は「左上の残り枚数」に変えた

### 4. レビューで直した点

別の担当がコードと実際の画面を読み合わせて確認し、次の不具合が見つかったので直した。

- 対面の見出し（名前・印・鳴き）が高さの計算に入っておらず、枠からはみ出すと全員の捨て牌が小さくなり続けた。見出しの高さを計算に入れ、対面の裏向きの手牌は「手牌13」の数字にした。縮めても効かない時は元に戻して止める
- 道場のレッスンで、ポン・ロンなどのボタンがコーチの吹き出しに隠れて押せなかった。吹き出しの位置は、光らせた場所と浮いているボタンを避けて決める
- 画面を回した後に四隅の幅が縮まず、捨て牌が小さいままになった
- 画面の大きさが変わるたびに全体を描き直していて、チュートリアルの光らせた場所が消えた。大きさだけ計算し直すようにした
- 局の情報の1行目が、捨て牌の段番号と同じ名前の設定で小さく薄くなっていた
- 対面の点数の増減が画面の上に出て見えなかった
- 上の段の「今」の札が切れていた。捨てた直後も次の置き場所の点線が残っていた。ボタンが多い時に手牌へ重なった
- 狭い画面では四隅のボタンの文字とスキルの数字を省いて、捨て牌に幅を回した

| 環境 | URL |

確認した内容：

- 844×390（iPhone 横）、667×375（iPhone SE 横）、932×430（大きいiPhone 横）、1280×720（PC）、390×844（縦持ち）で、重なり・はみ出しがないこと
- 捨て牌が多い局面でも収まること。条件は、1人19枚、リーチ、鳴かれた牌、鳴き2組
- 1局を最後まで打ってエラーが出ないこと、結果画面がスクロールなしで収まること
- 画面の見方ツアーで、光らせた場所と吹き出しが重ならないこと
- オンラインの参加者の画面で、席の向きと手番が正しいこと。この端末で交代の目隠し、道場のコーチ、会話シーンも確認した
