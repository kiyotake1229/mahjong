# カットイン演出（リーチ・ロン・ツモの瞬間を盛り上げる）

- 管理番号: #0047
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-11-06
- 関連: #0045（終局の演出）、#0046（着せ替えとライバル）

## 概要

「大規模な改修をしてもいい」という許可を受けて、対局中にいちばん盛り上がる瞬間（リーチ・ロン・ツモ）の見せ方を強くした。前は画面の真ん中に「リーチ」「ロン」と文字が一瞬出るだけだった。

打った人の顔と言葉を、斜めの帯にして画面を横切らせる（カットイン）。CPU のリーチ・あがりでも出るので、相手が動いた瞬間がはっきり分かり、振り込んだ時の「やられた」感も出る。

## 対象ファイル

- `index.html`

## 変更内容

- カットイン（`cutIn(pid, 言葉, 種類)`）：斜めの帯が左から入り、顔の丸（CPU はその人、自分は主人公の顔）と大きな言葉、名前を出して右へ抜ける。帯には光が走る
  - リーチ：赤いふち、短め（標準の速さで約0.7秒）。CPU の場合、リーチのひとことは帯が抜けてから出す
  - ロン・ツモ・ダブロン：金のふち（自分のあがりは緑のふち）、約0.9秒。帯が抜けてから結果の画面へ
  - 長さは対局の速さに合わせる（はやい 0.64秒／標準 0.88秒／じっくり 1.15秒）
- 出す場面：ひとり用と交代モード。レッスン中とオンライン対戦は今まで通りの文字だけ（オンラインは全員の画面の動きをそろえる仕組みに入れていないため）。端末の「視差効果を減らす（動きを減らす）」設定がオンの時も文字だけ
- あがりの入口は複数ある（CPU のロン、確認の後のロン、CPU のツモ、自分のツモ、自動ツモ）。1局で帯を出すのは1回だけにする（`G._ciWin`）。CPU のロンに自分も確認なしで加わる時なども、二重には出ない
- 前は CPU どうしのロンで、確認のあとにあがった時は文字も何も出ずに結果の画面になっていたが、そこにも帯が出る
- 設定の一番上に「カットイン演出：ON／OFF」（`mjCutin` に保存。初めは ON）
- 帯はタップを邪魔しない（`pointer-events:none`）。結果の画面より下に重なる
