- 種類: BUG（バグ修正）

- 作成日: 2026-10-06
- 関連: #0010（二段タップ）、#0033（待ちの表示）

## 概要

iPhone アプリ版をシミュレーターで動かす予定だったが、この Mac には Xcode 本体が入っておらず（コマンドラインツールだけ）、シミュレーターを使えなかった。代わりに、iPhone SE の横向きと同じ 667×375・タッチ操作の扱いで、Web 版（iPhone アプリ版と同じ中身）を初めて遊ぶ人と同じ状態から実際に操作した。主人公づくり → 第0章（3節とも最後まで） → 自由対局（二段タップ・ポン2回・チーの確認・この局は鳴かない・加槓・待ちの表示と詳細・順位の条件・速度の切り替え・リーチ・一発ツモ・相手のロン・次の局・続きから）。その中で次の4件を見つけて直した。

1. タッチ端末で、牌を捨てると、その位置に来た牌が浮いたまま見える
2. 第0章 第3節の冒頭の店主のセリフに、太字の記号「<b>」「</b>」がそのまま出る
3. 和了画面の「裏ドラ表示」に、表示牌ではなく裏ドラそのものが出ていた
4. 初心者モードの ON/OFF を覚えず、アプリを開くたびに ON に戻る

## 対象ファイル

- `index.html`

## 変更内容

### 1. 牌が浮いたまま見える（タッチ端末）

- 原因：手牌の「マウスを乗せると浮く」効果（`:hover`）が、タッチ端末ではタップのあとも残る。捨てた牌の位置に次の牌が詰めて来ると、その牌が浮いて見えていた。二段タップでは「選んだ牌」も浮くので、どれを選んでいるのか見分けにくかった
- 修正：浮く効果を、マウスなど本当に「乗せられる」端末（`(hover:hover) and (pointer:fine)`）だけにした。マウスで選んだ牌に乗せた時も、選んだ高さ（12px）のままにした

### 2. セリフに記号が出る

- 原因：会話の文字は記号を文字のまま表示する作り（安全のため）。この1行だけ太字の指定を書いていた
- 修正：「3枚の組を4つ」「同じ牌2枚（アタマ）」と、かぎかっこにした。会話として表示される行をすべて調べ、記号が入っていたのはこの1行だけ（ほかはレッスンの説明文で、太字が正しく表示される部分）

### 3. 裏ドラ表示

- 原因：画面左上の「ドラ表示」とふりかえりの「裏ドラ表示」は表示牌なのに、和了画面だけ裏ドラ（表示牌の次の牌）を出していた。表示牌 4萬 → 裏ドラ 5萬 の時に「裏ドラ表示: 5萬」と出て、「それなら裏ドラは 6萬では？」と混乱する
- 修正：「裏ドラ表示: 4萬 4筒（裏ドラは 5萬・5筒）」のように、表示牌と裏ドラを並べて出す

### 4. 初心者モードを覚えない

- 原因：右上の「初心者」スイッチの状態を保存していなかった。慣れた人は開くたびに OFF にし直す必要があり、待ちの表示も毎回、案内文の中に戻っていた
- 修正：端末に保存する（保存キー `mjBeg`）。初めての人は今までどおり ON
