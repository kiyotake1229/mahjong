# 見た目と音量（卓の色・牌をくっきり・BGMと効果音の音量）

- 管理番号: #0022
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-26
- 関連: #0005（設定画面）、#0010（打ち方の設定）

## 概要

長く遊ぶための細かな調整を設定画面に足した。卓の色（4色）、牌を見やすくする「くっきり」、BGMと効果音を別々に調整できる音量。これまで音は「あり／なし」しかなく、BGMだけ小さくしたい要望に応えられなかった。

## 対象ファイル

- `index.html`
- `README.md`

## 変更内容

### 1. 卓の色（`TABLE_THEMES`）

翠（既定）・藍・緋・墨の4色。卓の背景に使っている CSS 変数（`--felt`・`--bg0`・`--bg1`・`--bg2`）を `applyLook` で差し替えるだけなので、卓・ホーム・結果画面の背景がまとめて変わる。設定画面では丸い色見本を押すとすぐ変わる。端末に保存（`mjTheme`）。

### 2. 牌をくっきり（`mjTileHc`）

`body.tile-hc` を付けると、牌の白地を明るく・縁を濃く・絵柄のコントラストと彩度を上げる（CSS の `filter`）。牌の絵柄は変えない。

### 3. 音量（`mjVolBgm`・`mjVolSfx`）

- 効果音はこれまで直接スピーカーにつないでいた5か所を、まとめ役のゲイン（`sfxOut`）経由にし、その音量を効果音の音量にした
- BGM は曲ごとの基準音量に BGM の音量を掛ける。再生中に動かしてもその場で追従（`setVolumes`）
- 効果音のつまみは離した時に選択音を鳴らして試せる
- 「音楽・効果音：なし」はこれまでどおり全部止める
