# 点数計算の突き合わせツール（tools/scoring_check.js）

- 管理番号: #0011
- 種類: ENH（機能改善・品質）
- 対象: プロジェクト全体（ALL）。`tools/` と `index.html` の点数関数
- 作成日: 2026-09-25
- 関連: #0012（このツールで見つけた不具合の修正）

## 概要

「本格ルール」を名乗る以上、点数計算の間違いは致命的。これまでは人がプレイテストで見るだけだったので、役判定と支払い計算を機械的に点数表と突き合わせるツールを作った。ブラウザなしで `node tools/scoring_check.js` を流すだけで、約20の手と支払いの表（34通り×4）を確かめられる。

## 対象ファイル

- `tools/scoring_check.js`（新規）、`tools/README.md`（新規。tools の説明）
- `README.md`（構成に tools/ を追記）

## 変更内容

- `index.html` の script を Node の `vm` で読み込む。画面の部品は「何をされても壊れない空の要素」を代わりに渡し、読み込み時のエラーは無視して、`evaluate`・`payments`・`rankName` だけ取り出す
- 手の検査：平和ツモ／ロン、断幺（嵌張・赤ドラ）、七対子ツモ／ロン、役牌の暗刻、一盃口、三色同順、一気通貫、対々和（鳴き）、混一色（鳴き）、清一色、国士無双、四暗刻、大三元（鳴き）、字一色七対子、役なし。翻・符・含まれる役名を見る。役満は他の役が混ざらないこと（`only`）も見る
- 支払いの表：20〜110符 × 1〜4翻と、満貫・跳満・倍満・三倍満・役満を、子ロン／親ロン／子ツモ／親ツモの4通りで、標準の点数表（切り上げ満貫なし）と比べる
- NG があれば理由つきで1行出し、終了コード 1

## 確認URL

| 環境 | URL |
|---|---|

確認した内容：

- 初回の実行で、四暗刻に対々和と門前清自摸和が混ざって16翻になる不具合を検出（#0012 で修正）。ほかの NG は期待値の書き間違い（役牌の表記が「白」、三色の手が断幺も満たす、混一の手が一気通貫も満たす）だったので期待値を直した
- 修正後は手の検査20件・支払いの表34件がすべて一致
