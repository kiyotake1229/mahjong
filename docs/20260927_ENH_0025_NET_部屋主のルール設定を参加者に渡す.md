# オンライン対戦：部屋主のルール設定を参加者に渡す（九種九牌も参加者から）

- 管理番号: #0025
- 種類: ENH（機能改善）
- 対象: オンライン対戦（NET）
- 作成日: 2026-09-27
- 関連: #0013（ルールの設定。参加者側の課題として残していた分）

## 概要

#0013 で入れたルールの設定（対局の長さ・途中流局・流し満貫・責任払い・延長・アガリやめ・喰いタン・赤ドラ）はオンライン対戦では部屋主の端末で判定されるが、参加者の端末には伝わっていなかった。そのため参加者は「九種九牌」を宣言できず、あがりの可否の表示（喰いタンなしの時など）が部屋主と食い違うことがあった。部屋主が各参加者に送る局面の中にルール設定を入れ、参加者はそれで自分の設定を一時的に上書きし、部屋を出る時に元に戻すようにした。

## 対象ファイル

- `index.html`
- `README.md`

## 変更内容

- 部屋主：参加者ごとの局面（`projectFor`）に `rules`（`netRules()`：長さ・途中流局・流し満貫・責任払い・延長・アガリやめ・喰いタン・赤ドラ）を入れる
- 参加者：局面を受け取るたび（`guestApply`）に `applyNetRules` で設定の変数を上書き。最初の1回だけ元の値を `NET.savedRules` に控え、部屋を出る（`netShutdown`）時に `restoreNetRules` で戻す。端末への保存（`localStorage`）は書き換えない
- 九種九牌：参加者の手番でも条件を満たせばボタンが出て、押すと部屋主に `kyushu` を送る。部屋主は条件（第一巡・鳴きなし・1・9・字牌9種以上・途中流局あり）を確かめてから途中流局にする
- 設定画面：参加者の時は「ルール」の下に「オンライン対戦中は部屋主のルール設定が使われます」と案内
