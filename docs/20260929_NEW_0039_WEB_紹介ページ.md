## 概要

GitHub Pages にはアプリ本体とサポートページしかなく、アプリを知らない人に特徴を伝えるページがなかった。特徴・物語・学べる仕組み・遊び方・画面・ルール・よくある質問を1枚にまとめた紹介ページを作った。App Store の「マーケティング URL」（任意の欄）にも使える。制作実績として見せられる質のものにした。

## 対象ファイル

- `about/index.html`（新規。単一HTML。CSS・JS内包、外部読み込みなし）
- `about/img/`（新規。画面写真7枚：home・table・rank・result・story・dojo・records。1400×646 の JPEG、合計約0.8MB。共有用の画像 og.jpg 1200×630）
- `support.html`（上の案内と下の行に紹介ページへのリンク）
- `ios-app/岩崎さんへの引き渡し手順.md`（申請情報にマーケティング URL）
- `docs/README.md`（場所の略語に WEB を追加）
- `README.md`

## 変更内容

- 構成：上の帯（少し下がると背景が付く）／最初の画面（見出し「物語で覚える、本格4人打ち麻雀。」、遊ぶボタン、卓の写真を端末の枠に入れて浮かせ、白・發・中の牌と吹き出し）／数字の帯（10章・結末9つ・登場人物15人・レッスン8つ・役図鑑42種・実績35個。見えたら数え上げ）／特徴3つ／物語（章の一覧、主人公3人）／学べる仕組み4つ（道場・待ちと点数の見込み・順位と条件・初心者モード）／遊び方6つ／画面の一覧（横にスクロール、矢印ボタン）／ルール／よくある質問／最後の呼びかけ／下の行
- 数字や内容はアプリのコードとサポートページから数えて合わせた（登場人物は名前のある15人、章題は `index.html` の章の見出し、主人公3人は「祖父の店を探す学生・大手チェーンの新人・元ギャンブラー」）
- 動き：読み込み時に最初の画面がふわっと出る、スクロールで各部分が出る、ボタンの光、カードの浮き上がりとマウスに合わせた光。`prefers-reduced-motion` の時は動きを止める
- アイコンはすべて SVG（絵文字なし）。画像は遅延読み込み、幅・高さを指定して表示のずれを防ぐ
- 検索・共有：タイトル・説明・正規URL、OGP（共有時の画像・題名）、構造化データ（VideoGame、無料）
- 画面写真はアプリの撮影用の場面（`?shot=`）で撮った。卓の写真は、初心者モードOFF・オーラス・トップ・リーチなしで2-5筒待ちの場面に整えた（真ん中に待ちと点数の見込み、右上に順位）。相手は常連3人にそろえた
