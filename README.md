# 麻雀（4人打ち・CPU対戦）

## 現在の状態
- 公開中・遊べる状態。PWA対応（ホーム画面に追加でアプリとして起動、オフライン可）
- 公開URL: https://kiyotake1229.github.io/mahjong/
- リポジトリ: https://github.com/kiyotake1229/mahjong （`index.html` を push すると数十秒で反映）

## 構成

## 機能
- 4人打ち半荘（東場〜南場）。ツモ/ロン、立直（一発・裏ドラ）、ポン/チー/カン（暗槓・加槓・大明槓）、槍槓、ダブロン、赤ドラ（5萬5筒5索が各1枚。メニューでON/OFF）、フリテン、符計算と点数
- リーチ中にあがり牌を引いたら自動でツモ
- 対局中は上部「メニュー」から雀荘メニューへ。「対局にもどる」で再開できる
- 対応役：立直・一発・門前清自摸和・平和・断幺九・役牌・一盃口・二盃口・三色同順・三色同刻・一気通貫・対々和・三暗刻・七対子・混一色・清一色・混全帯幺九・純全帯幺九・混老頭・小三元・海底/河底・嶺上開花・ダブル立直・国士無双・大三元・四暗刻・字一色・清老頭・槍槓・赤ドラ
- 相手CPUに性格（鳴き派・守り派・リーチ派）。対局速度は「じっくり/標準/はやい」
- 自由対局でも常連（ハヤト・シズカ・ゲン・マスター。物語が進むとレン・クロダも）が卓に着き、対局中に吹き出しで掛け合いをする（開始・リーチ・和了・放銃・鳴き・流局・南場入り）
- 初心者モード：手番ガイド、おすすめ牌、鳴きの説明。相手のリーチ中はおすすめ牌が「現物」に切り替わり、押し引きの案内が出る
- 道場：8レッスン（牌のきほん／初あがり／リーチとロン／鳴きと守り／役とドラ／上級: フリテン・点数・七対子）。クイズ・クリア称号つき
- ストーリー「雀荘 翠」。会話はビジュアルノベル風の全画面シーン（場所ごとの背景＝翠の店内／閉店後／駅裏の路地／白い塔／雀荘 黒牌、立ち絵、名前札、一文字ずつ出るテキスト、タップで送り、選択肢）。対局のときだけ雀卓に戻り、「○○ 戦」のカットインで始まる。レッスン（道場形式の教え）は卓の上の吹き出しのまま。構成は「章」＞「節／戦」。メニューにはクリア済みと次に遊べるものだけが並び、先の章は「？？？」の1行だけ（ネタバレ防止）
  - 序章：主人公の名前と出自を選ぶ。出自が難易度になる（元ギャンブラー＝難しい：持ち点2万・ゲージ半減・相手が強め／学生＝標準／チェーンの新人＝やさしい：ゲージ2倍・相手が手加減）。出自でセリフや結末の一部が変わる
  - 第一章「翠の教え」全8節：牌のきほん／初あがり／鳴き／守り／リーチとロン／牌効率／押し引き／終章（本気の一局）。章の合間に閉店の伏線
  - 各節の前後に人物と店の物語（写真・咳・閉店の噂・出自ごとの会話）。第三〜七節はレッスンの後に「1局だけ実戦」を選べる（常連3人と1局。あがれなくても先へ進める。節のキャラが結果に一言）
  - 腕試しの各戦を突破すると「幕間」（ハヤトの不安、先代ユウジ、ゲンの鍵、レンの辞表、クロダの本音）。二度目の突破では別の幕間（出自で会話が変わる）
  - 第二章「腕試し」3戦：ハヤト→シズカ→ゲン。各戦の前にボスが「賭け」を持ちかけ、受けると相手が最強レベル・負ければバッドエンド（やり直し可）。賭けを受けたうえで「流儀」（直撃／振り込まない／満貫以上）を制すとボスの秘密が語られ、スキル（透視／千里眼／神引き）を託される。物語中のスキルは託されたものだけ使える
  - 第三章「岐路」：チェーン「マルヨシ」の買収の申し出。「翠を守る」（レン戦）／「新しい翠」（新キャラ クロダ戦）で分岐。岐路はやり直し可
  - 第五章「黒い手」（第四章クリアで解放）：地上げ屋・堂本との3連戦。第一夜は手下カラス、第二夜は堂本、決戦は堂本の雀荘で。堂本は配牌を積み込み、ツモも仕込む（イカサマ）。千里眼を使っている間は仕込めない。この部では託されていないスキルも全部使え、ゲージは1.5倍。負ければバッドエンド（やり直し可）。決戦で1位を取ると堂本のイカサマが暴かれ、称号「翠の守り手」
  - 第六章「白い塔」（第五章クリアで解放）：堂本を「掃除機」と呼ぶ黒幕・鷲尾。駅裏一帯の再開発を進める実業家で、一度も声を荒げず人を弱みから買う。序（来店）→ 代打ちミナト（元プロ、イカサマなし、振り込まないのが流儀）→ 鷲尾に借金を買われたハヤトと本気の対局（直撃で目を覚まさせる）→ 白い塔の決戦。鷲尾は卓の鏡でこちらの待ちを読み、テンパイ中の人間には振り込まない（自分がリーチした時だけ読めない）。配牌の積み込みもする。ツモとリーチの隙で1位を取ると、ミナトが鏡の角度を変えて投資家に不正を晒し、再開発は一夜で崩れる。称号「翠の灯」
  - 第四章「最後の一局」：マスター戦。結末は4つ（翠の主＝真エンド：守る道で1位かつ秘密3つ以上／翠の頂／新しい翠／閉店）。各結末に後日談、真エンドは出自ごとに締めが変わる
  - 翠ノート：出自・秘密・結末を集める収集ページ（16ページ）。「物語を最初から」で主人公を変えられる
- スキルゲージ（透視／千里眼／神引き）のオリジナル要素
