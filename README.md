# 麻雀（4人打ち・CPU対戦）

## 現在の状態
- 公開中・遊べる状態。PWA対応（ホーム画面に追加でアプリとして起動、オフライン可）
- 公開URL: https://kiyotake1229.github.io/mahjong/
- リポジトリ: https://github.com/kiyotake1229/mahjong （`index.html` を push すると数十秒で反映）

## 構成
```
index.html        アプリ本体（CSS/JS内包・単一ファイル）
manifest.json     PWA設定
sw.js             オフラインキャッシュ（HTMLはネットワーク優先）
icon-*.png / apple-touch-icon.png / favicon-32.png
```
通信なし・データは localStorage のみ（進捗・設定）。

## 機能
- 4人打ち東場。ツモ/ロン、立直（一発・裏ドラ）、ポン/チー/カン、フリテン、符計算と点数
- 相手CPUに性格（鳴き派・守り派・リーチ派）。対局速度は「じっくり/標準/はやい」
- 初心者モード：手番ガイド、おすすめ牌、鳴きの説明
- 道場：8レッスン（牌のきほん／初あがり／リーチとロン／鳴きと守り／役とドラ／上級: フリテン・点数・七対子）。クイズ・クリア称号つき
- ストーリー「雀荘 翠」：店主と常連3人（影絵ポートレート）に教わる全6章。最終章は本気の一局
- スキルゲージ（透視／千里眼／神引き）のオリジナル要素
