## オンライン対戦の仕組み
- 通信部品：PeerJS 1.5.5（cdnjs、SRI付き）。「みんなで対戦」でオンラインを選んだ時だけ読み込む。ひとり用は読み込まない
- 接続の仲介：PeerJS の無料公開サーバー（0.peerjs.com）。部屋IDは `suimj-room-` ＋部屋コード
- 対局の中身：端末どうしで直接（WebRTC）。部屋主が各参加者に「その人の手牌だけが入った状態」を送る（他人の手牌・山の並び・裏ドラは送らない）
- 死活確認：5秒ごと。45秒応答がなければ切断扱い。画面を裏に回した端末は「離れています」を知らせ、その間は90秒まで待つ
- 仲介サーバーだけが一時的に切れても、つながっている人との対局・待合室は続く（新しい人が入れないだけ）
- 中継サーバー（TURN）：標準で PeerJS の無料の公開中継（turn.peerjs.com。混み合うと使えない）を使う。自分で契約した中継は「みんなで対戦」→オンライン→「つながりにくい時（中継サーバーの設定）」に貼る（手順は下の「中継サーバーを使う手順」）。部屋を作った人の中継は参加者にも渡して使い、部屋主が交代した後も同じものを配る。参加者として設定した中継は、その人が交代で部屋主になっても自分の接続にだけ使い、ほかの人には配らない。会社・学校のWi-Fiの人は、その人の端末にも TLS（443番）の中継を設定する必要がある。「接続テスト」で直接接続と中継（UDP/TCP/TLS）の可否を確認できる
- 部屋主の交代：部屋主は局の開始時と点数が決まった直後に「全員に公開済みの情報だけ」の控え（点数・親・本場・供託・席の名前・合言葉のハッシュ）を送る。手牌・山は入れない。部屋主との接続が切れた参加者は、まず今の部屋と次の部屋（`-1`, `-2`…を付けた部屋ID）に問い合わせ、今の部屋が答えれば元の席に戻る（交代しない）。どこも答えなければ、控えの順番で時間をずらして次の部屋IDを取りに行く。仲介サーバーは同じIDを1人にしか登録させないので、新しい部屋主は必ず1人。局の途中だった時はその局を配り直し（点数は局の始め）、点数が決まっていた時は次の局から、終局していた時は終局画面から続ける。部屋が2つに割れた場合（旧部屋主が実は生きていた等）は、通信切れの席がある部屋主が10分間、前後の世代の部屋を20秒ごとに探し、「人の多い部屋、同じ人数なら世代の大きい部屋」にまとまる。移る側の部屋主は参加者に行き先を知らせて一緒に移る（両方が同時に移らないよう、仲介サーバーの名前を鍵にして1人だけが動く）
- 部屋主が対局中に「対戦をやめる」を押すと、ほかの人に部屋主を引き継いでもらう（待合室・終局の後なら部屋を閉じる）
- ひとことチャット：定型文8種の番号だけを送る（自由入力なし）。部屋主が番号を確かめてから配る。1人2秒に1回まで
- 再入室：部屋に入った時に端末へ合言葉と部屋の世代を保存。入り直す時は保存した世代から順に探す
- 版の違う端末どうしは待合室で「アプリの版が違います」になる（通信の版 2）
- 制限：新しい人の途中参加はできない（抜けた人の再入室はできる）。部屋主の交代中（数秒〜20秒）は操作できない。交代できるのは合言葉を持っている人がいる時だけ
- プライバシー：オンライン時は、仲介サーバー（0.peerjs.com）と相手の端末に IP アドレスと接続情報が渡る。直接つながらない時は PeerJS の公開中継、中継サーバーを設定した場合はその事業者のサーバーも通る（中身は暗号化されている）。開発側では何も保存しない。App Store の「データを収集しません」を続けるなら、サポートページ・申請メモにこの点を書き足すこと。チャットは定型文だけなので、利用者が作る内容（ガイドライン1.2）には当たりにくい
- sw.js：別ドメイン（CDN・仲介サーバー・中継サーバー）への通信はキャッシュしない（v7。manifest の名前や向きを変えるたびにキャッシュ名を更新している）。手元の確認用サーバー（localhost）では Service Worker を登録しない

## 中継サーバーを使う手順（つながらない回線がある時だけ）
登録や契約は利用者が自分で行う（アプリ側には鍵を入れていない）。
1. Metered（https://www.metered.ca/ ）で無料アカウントを作り、TURN サーバーのアプリを作る（無料枠の容量は Metered の料金ページで確認）
2. 管理画面の「Credentials」で認証情報を作り、「認証情報を取得するURL」（`https://〇〇.metered.live/api/v1/turn/credentials?apiKey=…`）をコピーする
3. アプリの「みんなで対戦」→オンライン→「つながりにくい時（中継サーバーの設定）」に貼って「保存」→「接続テスト」
4. ほかの事業者（Cloudflare・Twilio など）は、発行した接続情報のJSON（`urls`・`username`・`credential`）を貼る。期限付きのものは期限が切れたら貼り直す
- 設定は端末ごと（ホーム画面のアプリとブラウザでも別）。部屋主の設定は参加者にも渡るので、知っている人とだけ遊ぶ

## 機能
- 4人打ち半荘（東場〜南場。設定で東風戦にもできる。最後の局で誰も30000点に届いていなければ西入）。ツモ/ロン、立直（一発・裏ドラ）、ポン/チー/カン（暗槓・加槓・大明槓）、槍槓、ダブロン、赤ドラ（5萬5筒5索が各1枚。メニューでON/OFF）、フリテン、符計算と点数
- リーチ中にあがり牌を引いたら自動でツモ
- タイトル画面（雀荘 翠のロゴ、夜の街と卓、雨、白・發・中の牌。タップで開始）。ホーム画面（左：物語のカード＝主人公・次の節・進み具合・担当キャラ、右：自由対局／みんなで対戦／道場／翠ノート、下：ルールブック・画面の見方・常連の立ち絵。上：音・設定・タイトルへ）
- ひとり用の対局（自由対局・腕試し以降の戦・終節と練習の一局）は自動で端末に保存され、アプリを閉じてもホームの「続きから」で同じ場面から再開できる（レッスンと「みんなで対戦」は対象外）
- 対局中は右上の「メニュー」から「対局にもどる／画面の見方／ルールブック／設定／ホームにもどる」。物語やレッスンの最中は「この節（戦・レッスン）をやり直す」も出て、詰まった時にその場からやり直せる。ホームに戻っても対局は残り、「対局にもどる」で続きから
- 設定画面：CPUの強さ・打ち方（自動でロン・ツモ／鳴きの確認を出さない／リーチ後の自動ツモ切り／二段タップ＝1回目で選び2回目で捨てる／牌を大きめに）・ルール（対局の長さ／途中流局／流し満貫／責任払い／延長／アガリやめ／喰いタン）・見た目と音量（卓の色4色／牌をくっきり／BGM・効果音の音量）・おたすけモード・音・振動・赤ドラ・ひとこと・物語を最初から・不具合の記録（ホームの「設定」と対局中メニューの「設定」から）。不具合の記録は、エラーが起きた時刻・内容・場面を端末の中だけに残すもの（外に送らない）。進めなくなった時は「コピー」した内容を開発側に伝えると原因を追える
- 登場人物10人の立ち絵はフラットなイラスト調（顔・髪・服・小物あり。ポーズは通常／指さし／腕組み、表情は通常・笑顔・大笑い・怒り・落胆・驚き）。会話シーン・コーチの吹き出し・章の一覧・「○○ 戦」のカットイン・ホームで同じ絵を使い、卓上の掛け合いの吹き出しには表情つきの小さな顔が出る。主人公は出自ごとに立ち絵があり、序章・ホーム・物語の一覧に出る。画面案と立ち絵・UIキットは Claude Design のキャンバスにある（https://claude.ai/artifact/18ym42Gd8bKcnsRUMm3R1X ）
- 卓の画面（横画面）：左上に局の情報（局・本場・供託・残り枚数・ドラ表示）とスキル、右上にボタン。4人それぞれの枠（名前・風・点数・親／手番／リーチの印・鳴いた組・残りの手牌の数）に捨て牌を並べる。捨て牌はすべて正位置で、左から右・上の段から下の段へ（段の頭に何枚目か）。リーチ宣言牌は横向き＋赤線、鳴かれた牌は薄く＋鳴いた人の色の矢印、直前の捨て牌は金色の枠と「今」、手番の人の枠は光り、次に置く場所を点線で示す。真ん中には直前に捨てられた牌を大きく出し、誰が捨てたかを矢印と色で示す（その横に初心者向けの「今やること」）。席ごとに色が決まっていて、ひとことの吹き出しも同じ色。牌の大きさは画面の大きさから計算して、はみ出す時は自動で小さくする
- 対応役：立直・一発・門前清自摸和・平和・断幺九・役牌・一盃口・二盃口・三色同順・三色同刻・一気通貫・対々和・三暗刻・七対子・混一色・清一色・混全帯幺九・純全帯幺九・混老頭・小三元・海底/河底・嶺上開花・ダブル立直・国士無双・大三元・四暗刻・字一色・清老頭・槍槓・赤ドラ・三槓子・大四喜・小四喜・四槓子・緑一色・九蓮宝燈・天和・地和（役満は他の役やドラを数えない。暗槓も暗刻に数える）
- 今日の一局（ホーム右上）：日付で決まる同じ配牌で1局。相手は常連3人（ふつう）、収支を競い、今日のベスト・自己ベスト・連続日数を記録。何度でも挑戦できる
- 自由対局の相手えらび：下家・対面・上家を常連と物語で出会った相手から指名（おまかせも可）。CPUの強さと半荘／東風戦もここで選ぶ
- 局のふりかえり（和了・流局画面の「この局のふりかえり」、対局中のメニュー「前の局のふりかえり」）：全員の手牌・鳴き・待ち牌・リーチ／フリテン・役と、打牌の流れ（リーチ・鳴きの位置つき）。ひとり用と「この端末で交代」のみ
- 引き継ぎコード（設定 →「引き継ぎ」）：物語の進み・戦績・実績・設定を `SUI1.` で始まる文字列にまとめて書き出し、別の端末やアプリ版で貼って読み込む。途中の対局・不具合の記録・中継サーバーの設定は含めない
- 振動（設定 →「振動」）：打牌・鳴き・リーチ・あがり・流局・実績解除で短く振動。iOSアプリ版は Capacitor Haptics、Android のブラウザは `navigator.vibrate`、それ以外は何もしない
- 実績30個（初和了・役満・常連・トップ10回・役図鑑20種・流し満貫・道場皆伝・物語の終わり・今日の一局 など）。解除すると右上に帯が出て、戦績画面の「実績」タブに日付つきで残る
- 戦績と役図鑑（ホーム下の「戦績・役図鑑・実績」、対局中のメニュー「戦績」）：ひとり用の対局の対局数・順位の内訳・和了率・放銃率・立直率・副露率・流局時聴牌率・平均和了点・最高打点などと、役ごとのあがり回数（42種）。初めての役であがると和了画面に「役図鑑に追加」。レッスンと「みんなで対戦」は数えない
- 特殊ルール（設定の「ルール」であり／なし。初期値はあり）：途中流局（九種九牌・四風連打・四家立直・四槓散了）、流し満貫、責任払い（大三元・大四喜）、延長（西入）、アガリやめ、喰いタン、対局の長さ（半荘／東風戦）。レッスン・終節・練習の一局では途中流局と流し満貫は使わない
- 相手CPUに性格（鳴き派・守り派・リーチ派）。対局速度は「じっくり/標準/はやい」
- CPUの強さ（自由対局・みんなで対戦のCPU。物語の相手には影響しない。メニューで選ぶ）
  - やさしい：ときどき最善でない牌を切る、守らない、リーチを半分見送る、安いロンをたまに見逃す
  - ふつう：効率よく打ち、リーチされたら手が遠い時は降りる
  - つよい：見えている枚数で受け入れを数える。リーチには現物・リーチ後に通った牌・スジ・壁・見えている字牌の順で安全な牌を選び、役のない鳴き手や遠い手では降りる。降り中は鳴かない。残り枚数の多い待ちを選び、満貫以上はダマ
  - 鬼：つよい＋ドラ・赤・役牌の対子を残す打牌、ドラを危険寄りに扱う守り、高い1シャンテンは押す、4翻以上はダマ
- みんなで対戦（メニュー →「みんなで対戦」）
  - この端末で交代して遊ぶ：2〜4人。空いた席はCPU。自分の番（鳴き・ロンの確認を含む）が来ると名前が全画面に出るので、その人に端末を渡してタップ。それまで手牌は伏せて表示。鳴きの確認は「ポン・チー・ロンを聞く／聞かない（ロンは自動であがる）」を選べる。「聞かない」だと確認で端末を回さないので、手牌や待ちを周りに推測されにくい
  - オンラインで遊ぶ：部屋を作ると6文字の部屋コードと招待リンクが出る。最大4人、空いた席はCPU。部屋主の端末がゲームを進め、参加者は操作だけを送る（不正な操作は部屋主側で弾く）。参加者の持ち時間は打牌40秒・鳴き15秒（過ぎるとツモ切り／スルー）。参加者が抜けるとCPUが引き継ぎ、同じ端末から同じ部屋に入り直すと元の席に戻れる（部屋に入った時に端末へ合言葉を保存している）。部屋主が抜けても、残った人の端末が部屋主を引き継いで続ける。対局中は上の「ひとこと」（オンライン中は「新局」の位置）から定型文（よろしく・ナイス！・おしい！・うわー・考え中…・ごめん・ありがとう・おつかれ）を送れ、結果画面からも送れる。メニューで表示しないにもできる
- 自由対局でも常連（ハヤト・シズカ・ゲン・マスター。物語が進むとレン・クロダも）が卓に着き、対局中に吹き出しで掛け合いをする（開始・リーチ・和了・放銃・鳴き・流局・南場入り）
- まったくの初心者向け：
  - 「画面の見方」ツアー（11ステップ）：手牌・引いた牌・河・相手の名札と点数・真ん中の直前の捨て牌・局の情報と残り枚数・ドラ表示・案内・ボタン・スキルゲージ・メニューを順に光らせて説明。第二節「初めての和了」の最初に自動で出る（一度だけ）。メニューの「画面の見方」でいつでも再表示
  - おたすけモード（メニュー）：物語の相手が1段階弱くなり、スキルゲージが1.5倍溜まる。対局中に切り替えても反映
  - 初期の対局速度は「じっくり」
- ルール理解の助け：
  - 「いまの手を見る」（初心者モードの自分の番）：状態（何シャンテン・待ち・フリテン）、できている組、狙える役とその理由、おすすめの捨て牌と理由を表示
  - 和了画面で役名をタップすると説明が出る
  - ルールブック（メニュー／道場から）：はじめに／役（牌の例つき）／鳴きと守り／点数／用語 のタブ式

  - 第六章「白い塔」（第五章クリアで解放）：堂本を「掃除機」と呼ぶ黒幕・鷲尾。駅裏一帯の再開発を進める実業家で、一度も声を荒げず人を弱みから買う。序（来店）→ 代打ちミナト（元プロ、イカサマなし、振り込まないのが流儀）→ 鷲尾に借金を買われたハヤトと本気の対局（直撃で目を覚まさせる）→ 白い塔の決戦。鷲尾は卓の鏡でこちらの待ちを読み、テンパイ中の人間には振り込まない（自分がリーチした時だけ読めない）。配牌の積み込みもする。ツモとリーチの隙で1位を取ると、ミナトが鏡の角度を変えて投資家に不正を晒し、再開発は一夜で崩れる。称号「翠の灯」
