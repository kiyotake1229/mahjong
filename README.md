## オンライン対戦の仕組み
- 通信部品：PeerJS 1.5.5（cdnjs、SRI付き）。「みんなで対戦」でオンラインを選んだ時だけ読み込む。ひとり用は読み込まない
- 接続の仲介：PeerJS の無料公開サーバー（0.peerjs.com）。部屋IDは `suimj-room-` ＋部屋コード
- 対局の中身：端末どうしで直接（WebRTC）。部屋主が各参加者に「その人の手牌だけが入った状態」を送る（他人の手牌・山の並び・裏ドラは送らない）
- 死活確認：5秒ごと。45秒応答がなければ切断扱い（画面が裏に回っていた間は、戻った時点で数え直す）
- 仲介サーバーだけが一時的に切れても、つながっている人との対局・待合室は続く（新しい人が入れないだけ）
- 制限：TURN（中継サーバー）がないため、会社・学校のネットワークや一部のモバイル回線ではつながらないことがある。部屋主が抜けると対戦は終わる。新しい人の途中参加はできない（抜けた人の再入室はできる）。iPhone で長く画面を離れると切断扱いになりやすい
- プライバシー：オンライン時は、仲介サーバーと相手の端末に IP アドレスと接続情報が渡る。開発側では何も保存しない。App Store の「データを収集しません」を続けるなら、サポートページ・申請メモにこの点を書き足すこと
- sw.js：別ドメイン（CDN・仲介サーバー）への通信はキャッシュしない（v5）

## 機能
- 4人打ち半荘（東場〜南場）。ツモ/ロン、立直（一発・裏ドラ）、ポン/チー/カン（暗槓・加槓・大明槓）、槍槓、ダブロン、赤ドラ（5萬5筒5索が各1枚。メニューでON/OFF）、フリテン、符計算と点数
- リーチ中にあがり牌を引いたら自動でツモ
- 対局中は上部「メニュー」から雀荘メニューへ。「対局にもどる」で再開できる
- 対応役：立直・一発・門前清自摸和・平和・断幺九・役牌・一盃口・二盃口・三色同順・三色同刻・一気通貫・対々和・三暗刻・七対子・混一色・清一色・混全帯幺九・純全帯幺九・混老頭・小三元・海底/河底・嶺上開花・ダブル立直・国士無双・大三元・四暗刻・字一色・清老頭・槍槓・赤ドラ
- 相手CPUに性格（鳴き派・守り派・リーチ派）。対局速度は「じっくり/標準/はやい」
- CPUの強さ（自由対局・みんなで対戦のCPU。物語の相手には影響しない。メニューで選ぶ）
  - やさしい：ときどき最善でない牌を切る、守らない、リーチを半分見送る、安いロンをたまに見逃す
  - ふつう：効率よく打ち、リーチされたら手が遠い時は降りる
  - つよい：見えている枚数で受け入れを数える。リーチには現物・リーチ後に通った牌・スジ・壁・見えている字牌の順で安全な牌を選び、役のない鳴き手や遠い手では降りる。降り中は鳴かない。残り枚数の多い待ちを選び、満貫以上はダマ
  - 鬼：つよい＋ドラ・赤・役牌の対子を残す打牌、ドラを危険寄りに扱う守り、高い1シャンテンは押す、4翻以上はダマ
- みんなで対戦（メニュー →「みんなで対戦」）
  - この端末で交代して遊ぶ：2〜4人。空いた席はCPU。自分の番（鳴き・ロンの確認を含む）が来ると名前が全画面に出るので、その人に端末を渡してタップ。それまで手牌は伏せて表示。鳴きの確認は「ポン・チー・ロンを聞く／聞かない（ロンは自動であがる）」を選べる。「聞かない」だと確認で端末を回さないので、手牌や待ちを周りに推測されにくい
  - オンラインで遊ぶ：部屋を作ると6文字の部屋コードと招待リンクが出る。最大4人、空いた席はCPU。部屋主の端末がゲームを進め、参加者は操作だけを送る（不正な操作は部屋主側で弾く）。参加者の持ち時間は打牌40秒・鳴き15秒（過ぎるとツモ切り／スルー）。参加者が抜けるとCPUが引き継ぎ、同じ端末から同じ部屋に入り直すと元の席に戻れる（部屋に入った時に端末へ合言葉を保存している）
- 自由対局でも常連（ハヤト・シズカ・ゲン・マスター。物語が進むとレン・クロダも）が卓に着き、対局中に吹き出しで掛け合いをする（開始・リーチ・和了・放銃・鳴き・流局・南場入り）
- まったくの初心者向け：
  - 「画面の見方」ツアー（10ステップ）：手牌・引いた牌・河・相手の名札と点数・山と残り枚数・ドラ表示・案内バー・ボタン・スキルゲージ・メニューを順に光らせて説明。第二節「初めての和了」の最初に自動で出る（一度だけ）。メニューの「画面の見方」でいつでも再表示
  - おたすけモード（メニュー）：物語の相手が1段階弱くなり、スキルゲージが1.5倍溜まる。対局中に切り替えても反映
  - 初期の対局速度は「じっくり」
- ルール理解の助け：
  - 「いまの手を見る」（初心者モードの自分の番）：状態（何シャンテン・待ち・フリテン）、できている組、狙える役とその理由、おすすめの捨て牌と理由を表示
  - 和了画面で役名をタップすると説明が出る
  - ルールブック（メニュー／道場から）：はじめに／役（牌の例つき）／鳴きと守り／点数／用語 のタブ式
- 音：BGMと効果音をWebAudioで生成（外部ファイルなし）。場面ごとのBGM（店内・閉店後・路地・白い塔・黒牌）、対局中の穏やかなループ、ボス戦は緊張感のあるループ。文字送りのブリップ、選択、場面転換、カットインの効果音。メニューと会話画面でON/OFF
- 初心者モード：手番ガイド、おすすめ牌、鳴きの説明。相手のリーチ中はおすすめ牌が「現物」に切り替わり、押し引きの案内が出る
- 道場：8レッスン（牌のきほん／初あがり／リーチとロン／鳴きと守り／役とドラ／上級: フリテン・点数・七対子）。クイズ・クリア称号つき
- ストーリー「雀荘 翠」。会話はビジュアルノベル風の全画面シーン（場所ごとの背景＝翠の店内／閉店後／駅裏の路地／白い塔／雀荘 黒牌、立ち絵、名前札、一文字ずつ出るテキスト、タップで送り、選択肢）。対局のときだけ雀卓に戻り、「○○ 戦」のカットインで始まる。レッスン（道場形式の教え）は卓の上の吹き出しのまま。構成は「章」＞「節／戦」。メニューにはクリア済みと次に遊べるものだけが並び、先の章は「？？？」の1行だけ（ネタバレ防止）
  - 序章：主人公の名前と出自を選ぶ。出自が難易度になる（元ギャンブラー＝難しい：持ち点2万・ゲージ半減・相手が強め／学生＝標準／チェーンの新人＝やさしい：ゲージ2倍・相手が手加減）。出自でセリフや結末の一部が変わる
  - 第0章「はじめの一歩」全3節（序章の直後。第一章はこれをクリアすると開く）：
    - 第一節「麻雀って、何をするゲーム？」：卓の各所を光らせながら10ステップで説明（4人・136枚と山・配牌13枚・引いて捨てる・反時計回り・あがりの形・点数・8局・親）
    - 第二節「配牌、山、ツモ」：実際に「山から引く」ボタンで引き、好きな牌を捨て、3人が打つのを見て、河・残り枚数・ドラ表示を知る
    - 第三節「あがりの形」：あと1枚の配牌で順子4組を1つずつ確認、待ち牌クイズ、引いてツモあがり
    - 来店の会話（名前・出自ごとの語り）は第0章の冒頭に移動。第一章 第一節の導入は「勝つための話」に変更。道場からも「はじめの一歩」で復習できる
  - 第一章「翠の教え」全8節：牌のきほん／初あがり／鳴き／守り／リーチとロン／牌効率／押し引き／終章（本気の一局）。章の合間に閉店の伏線
  - 各節の前後に人物と店の物語（写真・咳・閉店の噂・出自ごとの会話）。第三〜七節はレッスンの後に「1局だけ実戦」を選べる（常連3人と1局。あがれなくても先へ進める。節のキャラが結果に一言）
  - 腕試しの各戦を突破すると「幕間」（ハヤトの不安、先代ユウジ、ゲンの鍵、レンの辞表、クロダの本音）。二度目の突破では別の幕間（出自で会話が変わる）
  - 第二章「腕試し」3戦：ハヤト→シズカ→ゲン。各戦の前にボスが「賭け」を持ちかけ、受けると相手が最強レベル・負ければバッドエンド（やり直し可）。賭けを受けたうえで「流儀」（直撃／振り込まない／満貫以上）を制すとボスの秘密が語られ、スキル（透視／千里眼／神引き）を託される。物語中のスキルは託されたものだけ使える
  - 第三章「岐路」：チェーン「マルヨシ」の買収の申し出。「翠を守る」（レン戦）／「新しい翠」（新キャラ クロダ戦）で分岐。岐路はやり直し可
  - 第五章「黒い手」（第四章クリアで解放）：地上げ屋・堂本との3連戦。第一夜は手下カラス、第二夜は堂本、決戦は堂本の雀荘で。堂本は配牌を積み込み、ツモも仕込む（イカサマ）。千里眼を使っている間は仕込めない。この部では託されていないスキルも全部使え、ゲージは1.5倍。負ければバッドエンド（やり直し可）。決戦で1位を取ると堂本のイカサマが暴かれ、称号「翠の守り手」
  - 第六章「白い塔」（第五章クリアで解放）：堂本を「掃除機」と呼ぶ黒幕・鷲尾。駅裏一帯の再開発を進める実業家で、一度も声を荒げず人を弱みから買う。序（来店）→ 代打ちミナト（元プロ、イカサマなし、振り込まないのが流儀）→ 鷲尾に借金を買われたハヤトと本気の対局（直撃で目を覚まさせる）→ 白い塔の決戦。鷲尾は卓の鏡でこちらの待ちを読み、テンパイ中の人間には振り込まない（自分がリーチした時だけ読めない）。配牌の積み込みもする。ツモとリーチの隙で1位を取ると、ミナトが鏡の角度を変えて投資家に不正を晒し、再開発は一夜で崩れる。称号「翠の灯」
  - 第四章「最後の一局」：マスター戦。結末は4つ（翠の主＝真エンド：守る道で1位かつ秘密3つ以上／翠の頂／新しい翠／閉店）。各結末に後日談、真エンドは出自ごとに締めが変わる
  - 翠ノート：出自・秘密・結末を集める収集ページ（16ページ）。「物語を最初から」で主人公を変えられる
- スキルゲージ（透視／千里眼／神引き）のオリジナル要素
