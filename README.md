## 機能
- 4人打ち東場。ツモ/ロン、立直（一発・裏ドラ）、ポン/チー/カン、フリテン、符計算と点数
- 相手CPUに性格（鳴き派・守り派・リーチ派）。対局速度は「じっくり/標準/はやい」
- 初心者モード：手番ガイド、おすすめ牌、鳴きの説明
- 道場：8レッスン（牌のきほん／初あがり／リーチとロン／鳴きと守り／役とドラ／上級: フリテン・点数・七対子）。クイズ・クリア称号つき
- ストーリー「雀荘 翠」（影絵ポートレート・語りパート付き）
  - 序章：主人公の名前と出自を選ぶ。出自が難易度になる（元ギャンブラー＝難しい：持ち点2万・ゲージ半減・相手が強め／学生＝標準／チェーンの新人＝やさしい：ゲージ2倍・相手が手加減）。出自でセリフや結末の一部が変わる
  - 第一部「翠の教え」全8章：牌のきほん／初あがり／鳴き／守り／リーチとロン／牌効率／押し引き／終章（本気の一局）。章の合間に閉店の伏線
  - 第二部「腕試し」3戦：ハヤト→シズカ→ゲン。各戦の前にボスが「賭け」を持ちかけ、受けると相手が最強レベル・負ければバッドエンド（やり直し可）。賭けを受けたうえで「流儀」（直撃／振り込まない／満貫以上）を制すとボスの秘密が語られ、スキル（透視／千里眼／神引き）を託される。物語中のスキルは託されたものだけ使える
  - 第三部「岐路」：チェーン「マルヨシ」の買収の申し出。「翠を守る」（レン戦）／「新しい翠」（新キャラ クロダ戦）で分岐。岐路はやり直し可
  - 終章：マスター戦。結末は4つ（翠の主＝真エンド：守る道で1位かつ秘密3つ以上／翠の頂／新しい翠／閉店）
  - 翠ノート：出自・秘密・結末を集める収集ページ（10ページ）。「物語を最初から」で主人公を変えられる
- スキルゲージ（透視／千里眼／神引き）のオリジナル要素
