# tools/ — 開発用の補助スクリプト

アプリの動作には関係しない。アプリ本体は `index.html` だけで完結している。

## scoring_check.js — 点数計算の突き合わせ

`index.html` の中の役判定（`evaluate`）と支払い計算（`payments`）を Node で読み込み、既知の手と点数表と比べる。ブラウザは要らない。

```bash
node tools/scoring_check.js
```

- 手の検査：平和・断幺・七対子・役牌・一盃口・三色・一気通貫・対々和・混一色・清一色・国士無双・四暗刻（暗槓入りも）・大三元・字一色・九蓮宝燈・大四喜・小四喜・四槓子・緑一色・天和・地和・喰いタン・役なし など約30手。翻数・符・含まれる役名を見る（役満は他の役が混ざらないことも見る）
- 喰いタンなし（`KUITAN=false`）で鳴いた断幺九が役なしになること
- 責任払い（パオ）の分担 `paoShares`：ツモは全額、他家からのロンは折半、本場の扱い
- 支払いの表：20符2翻〜110符2翻、満貫〜役満まで、子ロン／親ロン／子ツモ／親ツモの4通り（切り上げ満貫なし）
- NG があれば1行ずつ理由を出し、終了コードが 1 になる

役の判定や点数の計算を直したら、必ずこれを流してから push する。新しい手を足すときは `CASES` に1行足す（牌の表記：`123m 45p 6s`、字牌は `E S W N P F C`、赤5は `0m 0p 0s`）。
