## 1. 1分版（エレベーターピッチ）

> 4人打ちの本格麻雀です。ルールは省略していません。立直・鳴き・カン・符計算・フリテンまで全部入っています。
>
> ただ、いちばん力を入れたのは **「麻雀を知らない人が遊びながら覚えられる」** ところです。
> 道場の8レッスンと、雀荘「翠」を舞台にしたストーリーで、店主と常連に教わりながら対局します。
> 初心者モードでは「今どの牌を切ればいいか」「なぜか」を毎回教えてくれます。
>
> これが 1つのHTML、約270KB に入っていて、通信なし・端末内保存で動きます。
> Web版は公開済み、PWA対応済み。iOS化はコツコツと同じ手順で半日です。

### 2-1. 何のアプリか（30秒）

- 4人打ちの麻雀。CPU3人と半荘を打つ
- 狙いは「覚えるまでの壁を消す」。麻雀は遊びたい人が多いのに、ルールと相手の問題で始められない
- Web版は完成して公開中。PWA対応済み

### 2-2. 全体像（30秒）

- 入口は3つ。**道場**（レッスン）、**ストーリー「雀荘 翠」**（物語で覚える本体）、**自由対局**（腕試し）
- どこから入っても同じ卓に戻る。初心者モードとおたすけモードが全部を支える

### 2-3. デモ（3分）※台本

**① ストーリーの会話シーン（30秒）**
> 「ストーリーモードです。雀荘『翠』の店主と常連に教わる話で、会話はこういう全画面のシーンで進みます。背景も立ち絵も全部SVGで描いていて、画像ファイルはありません」
> （タップで数行送る）「選択肢で出自を選ぶと難易度が変わります」

**② 対局・初心者モード（1分）**
> （対局に入る）「自分の番になると、案内とおすすめの牌が出ます。**なぜその牌かも書いてある**。相手がリーチしたら、おすすめが安全な牌に切り替わります」
> （「いまの手を見る」を押す）「今の手が何シャンテンで、何を狙えるか、ここで確認できます」

**③ 和了と役の説明（1分）**
> （あがれたら）「あがると牌がめくれて役が順に出て、点数がカウントアップします。**役名をタップすると説明が出る**ので、『なぜあがれたか』がその場で分かります」
> ※ あがれない場合は「メニュー → ルールブック」で役の一覧（牌の例つき）を見せる

**④ メニューの助け機能（30秒）**
> 「メニューには、画面の見方ツアー、おたすけモード、ルールブックがあります。まったくの初心者でも詰まらないようにしました」

**⑤ 機内モード（30秒）※必ず見せる**
> （機内モードにする）「このまま全部動きます。**通信を一切使っていない**ので、電波がなくても遊べます。うちの方針そのままです」

### 2-4. 現状（30秒）

- Web版 完成・公開中、PWA対応済み。通信なし・端末内保存
- 道場8レッスン、物語6章、自由対局、翠ノート
- プレイテストで見つかった点数・フリテン・符の不具合は修正済み

### 2-5. 次のステップとお願い（30秒）

- iOS化は Capacitor で半日（コツコツの `ios-app/` が雛形）。その後、実機確認 1〜2日
- 費用は Apple Developer Program（年12,800円）だけ。コツコツと同じアカウントで出せる
- **お願いしたいこと**：コツコツの次に麻雀を iOS 化する順番でよいか

## 3. 想定質問と答え

| 質問 | 答え |
|---|---|
| 麻雀は審査で「ギャンブル」扱いにならない？ | 現金・課金・賭け要素は一切なし。点数はゲーム内だけ。物語の「賭け」は演出で、負けると物語がやり直しになるだけ。同種の麻雀ゲームは多数審査を通っている。年齢制限は 4+ で申請し、指摘があれば「疑似ギャンブル：まれ/軽度」に変えて対応する |
| CPUは強い？ | 性格3種（鳴き派・守り派・リーチ派）。物語のボスは段階的に強く、手読み（人間の待ちに振り込まない）や積み込みをする特別なAI。自由対局の相手は標準的な強さ |
| 初心者は本当に覚えられる？ | 道場のレッスン → 物語で会話しながら実戦 → 自由対局、の順で段階を踏む。初心者モードは毎回「なぜその牌か」を説明する。おたすけモードで難易度も下げられる |
| 音は？ | BGM・効果音は Web Audio で合成。音源ファイルなし。メニューでON/OFF |
| 重くない？ | 単一HTML 約270KB。3D等はなく、古めのスマホでも動く。スマホ幅（375px）で14枚の手牌が収まるよう調整済み |
| データは？ | 端末内のみ（進捗・設定）。通信ゼロ。App Store のプライバシーは「収集しません」 |
| 審査4.2（WebViewだけのアプリ）は？ | 完全オフライン・端末内保存・継続利用（物語の進行・道場の記録）。iOS化時に触覚フィードバックを加える。コツコツと同じ根拠 |
| Android は？ | Web版（PWA）がそのまま動く。ストア配布が必要なら Capacitor で Android も生成できる |
| 直したいときは？ | `index.html` を直して push すれば Web版は数十秒で反映。iOS版は `npm run sync` → Xcode で再ビルド |

## 4. 話し方のコツ

- 最初の30秒で「本格ルール」「初心者が覚えられる」「通信なし」の3点を言い切る
- デモは**スマホを持って操作しながら**話す。スライドは補助で、読み上げない
- 「おすすめ牌と理由」と「機内モードで全部動く」の2か所は必ず見せる。あがれるかは運なので、あがれなければルールブックで代替
- 数字は3つまで（270KB／8レッスン／6章）。多く言わない
- 最後は「お願いしたいこと」を具体的に言って終わる
