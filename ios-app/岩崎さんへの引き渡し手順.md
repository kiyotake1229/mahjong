岩崎さん

4人打ち麻雀ゲーム「雀荘 翠（すい）」の iOS プロジェクトです。
**Xcode で開いてビルド → App Store 申請** まで進められる状態になっています。

## 1. アプリ概要

| 項目 | 内容 |
|------|------|
| アプリ名 | 雀荘 翠 |
| Bundle ID | `work.ltv.sui`（変更する場合は Xcode の Signing & Capabilities で） |
| 構成 | Capacitor 7（WebView 同梱型ネイティブアプリ）。本体は `../index.html` 1ファイル |
| 対応 | iPhone / iPad。**横画面のみ**（縦にしても回転しない設定） |
| 通信 | 基本なし（ひとり用の全モードはオフラインで動作）。**「みんなで対戦」のオンラインを選んだ時だけ**、相手の端末と WebRTC で直接通信（接続の仲介に PeerJS の公開サーバー）。アカウント・自社サーバーなし |
| データ | 端末内のみ（localStorage）。物語の進み・戦績・設定など。外部送信・収集なし |
| ネイティブ機能 | 触覚フィードバック（打牌・鳴き・リーチ・あがり・実績解除で振動） |
| 収益化 | なし（無料・広告なし・課金なし） |

## 3. ビルド手順

このフォルダ（`ios-app/`）で、以下を順に実行してください。

```bash
# 1) 依存パッケージを取得（node_modules を消してあるので必ず実行）
npm install

# 2) Web アプリを同梱し、iOS プロジェクトへ反映（pod install も走る）
LANG=en_US.UTF-8 npm run sync

# 3) Xcode で開く
open ios/App/App.xcworkspace
```

> **注意**: 必ず `App.xcworkspace` を開いてください（`App.xcodeproj` ではありません）。
> `pod install` で「requires your terminal to be using UTF-8」と出たら、上のように `LANG=en_US.UTF-8` を付けてください。

### Xcode 上での設定

1. 左ペインで **App** を選択 → **Signing & Capabilities** タブ
2. **Team** に自社の Apple Developer アカウントを選択（"Automatically manage signing" は ON）
3. 必要に応じて **Bundle Identifier** を自社のものに変更（既定は `work.ltv.sui`）
4. **General** タブで **Version**（例: 1.0.0）と **Build**（例: 1）を設定
5. **General → Deployment Info** の Device Orientation が **Landscape Left / Landscape Right だけ**にチェックされていることを確認（Info.plist で設定済み。もし Portrait にチェックが付いていたら外す）

### 動作確認

上部のデバイス選択から実機またはシミュレータ（iPhone 15 Pro Max など）を選び ▶ で起動。
起動したら次を確認してください。

- タイトル画面 → タップでホーム画面。横向きで表示され、ノッチ（画面の切り欠き）に文字が重ならない
- 「自由対局」で牌が切れ、CPU が打ち進む。牌を捨てた時に軽く振動する（実機のみ）
- アプリを閉じて開き直しても、ホームの「続きから」で対局が戻る
- 設定 → 「サポート・プライバシー」が開く

## 4. App Store 申請

1. Xcode: **Product → Archive**
2. Organizer が開いたら **Distribute App → App Store Connect** でアップロード
3. [App Store Connect](https://appstoreconnect.apple.com) でアプリ情報を入力して審査提出

**アプリ名（30字以内）**
```
雀荘 翠 - 物語で覚える4人打ち麻雀
```

**サブタイトル（30字以内）**
```
はじめてでも打てる。常連と、みんなと。
```

**説明文**
```
駅裏の小さな雀荘「翠」を舞台にした、4人打ち麻雀ゲームです。
まったくの初心者は物語の第0章から。店主と常連が、実際に打ちながら教えてくれます。

■ 物語で覚える

序章から第六章まで、雀荘「翠」の人たちとの物語を進めながら、麻雀を身につけていきます。
```

## 5. 審査で見られやすい点

Apple ガイドライン **4.2（最低限の機能）** について、本アプリは以下を満たしています。

- 完全オフラインで動作する自立したゲーム（Web サイトの単なる表示ではない）
- 端末内にデータを保存し、継続的に利用する設計（物語の進み・自動保存・戦績・実績）
- ネイティブの触覚フィードバックを実装

そのほか、初回起動で見ていただきたい点：

- **横向き固定**：縦にしても回転しないこと。ホーム画面のアプリとしてではなく App として動くので、本体側の「横向きにしてください」の画面は出ないはずです
- **安全域**：`capacitor.config.json` の `contentInset` は `never`（本体の CSS が切り欠きを避ける）。もし左右の端が切り欠きに隠れる端末があれば、`always` に変えて `npm run sync` してください
- **音**：BGM・効果音は端末内で合成しています。サイレントスイッチが入っていると鳴りません（仕様）

## 6. アプリ内容を修正したい場合

アプリ本体は 1つ上のフォルダの `index.html` です。修正後、このフォルダで：

```bash
LANG=en_US.UTF-8 npm run sync
```

を実行すると iOS プロジェクトに反映されます。その後 Xcode で再ビルドしてください。
Web 版（https://kiyotake1229.github.io/mahjong/）は `index.html` を GitHub に push すると数十秒で更新されます。

### アイコンを差し替える

`assets/icon.png`（1024×1024・透過なし）と `assets/logo.png`（スプラッシュ用・透過あり）を差し替えて `npm run icons`。

### 変更の記録

仕様と変更の記録は `../docs/` にあります（`../docs/README.md` が目次）。
